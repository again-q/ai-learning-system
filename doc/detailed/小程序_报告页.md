## 1. 页面清单

| 页面 | 路径 | tabBar | 功能 |
|------|------|--------|------|
| 报告页 | pages/report/report | 否（诊断完成后跳转） | 逐题展示诊断结果 + 异议入口 + 修正弹层 |

## 2. 页面交互规则

- **加载**：页面参数 batchId → 调 getReport 获取报告数据
- **展示**：逐题卡片，每张卡片显示：
  - 题号 + 题目文本
  - 对错标记（✅/❌）+ 题型 + 难度档位（如"L4 中下题"）
  - 判定依据：过程分 P、路径质量 η（解答题）、知识点
  - **「我觉得不对」按钮**（每张卡片底部）
- **异议流程**：点「不对」→ 弹出修正弹层 → 回显当前判定字段（题目文本、作答、难度档位）→ 学生修改关键字段 → 提交 → 调 disputeQuestion → 该题卡片刷新为新结果 → Toast「已重新诊断」
- **加载状态**：初次加载显示骨架屏；单题重诊时该题卡片显示重新分析动画
- **空状态**：无题目时显示「本批次无有效题目」
- **错误状态**：单张失败显示「分析失败」+ 原图缩略图 + 「重新上传」引导

## 3. API 调用映射

| 功能 | 云函数 | URL | 请求 | 响应关键字段 |
|------|--------|-----|------|------------|
| 获取报告 | diagnose | GET /getReport?batchId= | batchId | questions[], failedItems[] |
| 异议修正 | dispute | POST /disputeQuestion | questionId, corrections | newDiagnosis |

## 4. 状态与存储

- **页面 data**：`{batchId, questions:[], loading:true, disputingId:null}`
- **参数传递**：batchId（从拍照页传来）

## 5. 微信能力使用

| 能力 | 目的 |
|------|------|
| 无额外能力 | 报告页仅数据展示 |

## 6. 生命周期钩子

| 钩子 | 动作 |
|------|------|
| onLoad(options) | 读取 options.batchId，调 getReport |
| onShow | 无特殊处理（不需要每次刷新） |

## 7. 错误处理

| 场景 | 处理 |
|------|------|
| 报告加载失败 | Toast「加载失败，请重试」+ 重试按钮 |
| 异议提交失败 | Toast「修正失败，请重试」 |
| batchId 无效 | Toast「批次不存在」+ 返回首页 |

## 8. 分包策略

无分包。

## 9. 缓存策略

无。

## 10. 测试要点

| 场景 | 预期 |
|------|------|
| 拍照完成后跳转 | 展示 4 题诊断结果 |
| 点「我觉得不对」修改作答 | 该题卡片刷新 |
| 单张失败 | 该题显示失败状态，其他题正常 |
| 返回后重新进入 | 从数据重新渲染 |
