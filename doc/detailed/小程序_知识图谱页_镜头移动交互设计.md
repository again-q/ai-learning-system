## 1. 目标

将知识图谱页从「层级切换」改造为**镜头移动聚焦**交互：点击节点时，整个图谱世界平移，被点节点滑到中心并逐渐放大变蓝成为新中心，旧层节点淡出消失，下一级子节点在移动过程中同步慢慢浮现。

## 2. 交互总览（用户确认的四件事，0.65s 一条时间轴）

```
点击节点（世界坐标 twx, twy）
├─ ① 整个世界（节点+线容器 .world）整体平移：translate(CENTER - twx, CENTER - twy)
│     transition 0.65s cubic-bezier(0.3, 0.9, 0.3, 1)
├─ ② 旧层所有节点（含原中心）淡出消失：opacity 1→0，0.35s ease
├─ ③ 被点节点聚焦：64px→120px 放大 + 白→蓝渐变，0.65s（与移动同步）
└─ ④ 下一级子节点浮现：从中心 scale 0.45/opacity 0 → 目标位 scale 1/opacity 1，0.75s，delay 40ms（比移动略慢，有"慢慢浮现"延时感）
```

返回：当前层淡出 → 世界平移回上一级中心 → 重建。

## 3. 页面结构

```
page（disableScroll: true，固定 600px 高舞台）
└─ #stage（position: relative; height: 600px; overflow: hidden）
   ├─ #world（position: absolute; inset: 0; transform-origin: 0 0）  ← 整个图谱世界
   │  ├─ 连线层（view 细条 × N，绝对定位）
   │  └─ 节点层（view.node × N，绝对定位）
   └─ 提示条 / 分圈按钮（不随世界移动，stage 直属）
```

### 3.1 世界坐标制（核心）

- **世界坐标**：节点在 `.world` 内的绝对坐标（left/top）。视口 = 世界经过 transform 平移后的可视区域。
- **不变量**：`world.transform = translate(CENTER.x - centerWorld.x, CENTER.y - centerWorld.y)`，其中 `centerWorld` 是当前中心节点的世界坐标。
- **初始**：中心节点世界坐标 = `{x: 195, y: 128}`（视口中心），transform = none。
- **进入**：点击节点 P（世界坐标 twx, twy）→ transform 更新为 `translate(195 - twx, 128 - twy)` → P 到达视口中心。
- **子节点世界坐标**：`world(x, y) = 视口布局坐标(x, y) + (centerWorld - CENTER)`——新子节点按"以新中心为基准的视口布局"换算成世界坐标，随世界移动后落在正确视口位置。

### 3.2 节点定位

```
.node { position: absolute; left: wx px; top: wy px; transform: translate(-50%, -50%); }
```

## 4. 状态机

```
IDLE ──点击有效子节点──▶ FOCUSING（busy=true）
FOCUSING ──700ms 定时器──▶ IDLE（busy=false；清理旧节点、更新 current/stack）
返回/面包屑 ──▶ GOING_BACK（busy=true）──650ms──▶ IDLE（重建）
```

- `busy` 期间拒绝新导航（防连点错乱）。
- 兜底：FOCUSING/GOING_BACK 各加一个 1.1s/1.0s 强制释放 busy 的定时器（防异常卡死）。

## 5. 动画细节

### 5.1 世界移动

| 属性 | 值 |
|---|---|
| 属性 | transform |
| 时长 | 0.65s |
| 曲线 | `cubic-bezier(0.3, 0.9, 0.3, 1)`（iOS 质感） |
| 触发 | 直接改 inline transform（transition 常驻） |

### 5.2 被点节点聚焦（变蓝放大）

```
.node.focusing .dot { transition: width/height 0.65s, background 0.65s, color 0.4s, box-shadow 0.6s, font-size 0.5s; }
被点节点加 class 'focusing center' → .dot 从 64px 白圆过渡到 120px 蓝渐变圆
```

- 蓝渐变：`linear-gradient(135deg, #6cc3ff 0%, #007aff 58%, #004ecb 100%)`
- 聚焦完成后移除 `focusing`（保留 `center`）。

### 5.3 子节点浮现

```
.node.reveal { transition: transform 0.75s cubic-bezier(0.3, 0.9, 0.3, 1), opacity 0.75s ease; }
.node.reveal.origin { transform: translate(0,0) scale(0.45); opacity: 0; }
渲染时带 'reveal origin'，40ms 后移除 origin → 从中心散开浮现
```

- 40ms 用 setTimeout（不用 rAF，防失焦卡住——原型踩坑记录）。

### 5.4 旧层淡出

```
.node.oldfade { transition: opacity 0.35s ease; opacity: 0 !important; }
```

- 纯淡出（不做 scale），700ms 后从 DOM 移除。

## 6. 连线渲染（小程序无 SVG → view 细条方案）

每条连接线 = 一个 view 细条，跟随世界移动：

```
线 view：position: absolute
- 锚点：起点 = 中心圆边 (cx, cy+cR)，终点 = 子节点圆顶 (x, y-kR)
- 长度 L = dist(起点, 终点)，宽度 2rpx（#007aff，opacity 0.2）
- 旋转：angle = atan2(dy, dx)，transform: rotate(angle)（transform-origin: 0 50%）
- 贝塞尔曲线 → 用 2 段折线近似（水平段 + 斜线段），或单条斜线 + 竖线两段：
  段1：中心底部 → 弯点 midY（垂直）
  段2：弯点 → 子节点顶部（斜线）
```

实现函数 `edgeView(x1, y1, x2, y2, midY)`：返回两条 view 的样式对象（世界坐标）。

## 7. 分组分圈（子节点 >8）

| 条件 | 行为 |
|---|---|
| 子节点 ≤ 8 | 直接平铺（每行 4 个，两行） |
| 子节点 > 8 | 按 type 分组：概念×N / 性质×N / 方法×N / 记号×N（≤4 组单行），点组进入组内 |
| 组内 > 8 | 分圈：每圈 8 个，底部「下一圈 ›」按钮循环切换 |

分组顺序固定：definition → property → method → notation。

## 8. 演化模式（保留 v1 机制）

- 右上角切换「演化」：只显示**前置祖先链 + 当前节点**（用户 2026-08-10 确认：去掉儿子）
- 祖先垂直堆叠（动态间距，间距 = min(66, 可用空间/(n-1))），当前节点居中偏下（104px 小号中心）
- 演化模式不触发镜头移动（轻量切换），返回结构模式走 exitEvo。

## 10. 性能与兼容

| 项 | 方案 |
|---|---|
| 动画 | 全部 transform/opacity（GPU 合成层），无 layout 动画 |
| 节点数 | 单层 ≤ 8 节点 + 线 ≤ 8 条 × 2 段 = ≤16 个 view，无压力 |
| 基础库 | view transform/transition 全版本支持（同层渲染） |
| 页面滚动 | disableScroll: true（分组分圈保证内容 ≤528px < 600px，无需滚动——解决原生 canvas 滚动错位问题） |
| 错误兜底 | busy 超时强制释放；setTimeout 替代 rAF |

## 11. 验收标准

1. 点击单元 → 世界整体平移 + 旧层淡出 + 节点变蓝放大 + 子节点同步浮现（0.65s 一条时间轴）
2. 变蓝为渐变（无跳变），放大平滑
3. 快速连点不卡死（busy 防抖 + 兜底释放）
4. 返回/面包屑回退正确
5. 分组分圈：1.1（10 节点）→ 4 组；组内 >8 分圈可切换
6. 演化模式：祖先链 + 当前，无儿子
7. 拖动无错位（页面不滚动）
8. 线与节点对齐（世界坐标制）
