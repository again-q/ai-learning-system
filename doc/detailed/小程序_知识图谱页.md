## 1. 页面清单

| 页面 | 路径 | tabBar | 功能 |
|------|------|--------|------|
| 知识图谱页 | pages/graph/graph | 是（图标：graph） | 按章→节→知识点层级浏览 |
| 知识点详情页 | pages/graph/detail | 否（从图谱页点击进入） | 单知识点概念说明 |

## 2. 页面交互规则

- **导航**：底部 tabBar「知识图谱」进入
- **层级浏览**：首次展示章列表（根节点）→ 点击章 → 展示该章下的节 → 点击节 → 展示该节下的知识点
- **节点详情**：点击知识点 → 跳转详情页，展示 name / type / concept.sourceText / importance
- **返回**：详情页左上角返回按钮；图谱页内通过面包屑或返回按钮回到上一层
- **加载态**：骨架屏（列表占位）
- **空状态**：无数据时显示「图谱加载中，请稍候」

## 3. API 调用映射

| 功能 | 云函数 | URL | 请求 | 响应关键字段 |
|------|--------|-----|------|------------|
| 层级查询 | graphService | GET /getGraph?parentId= | parentId（空=根） | nodes[], childCount, hasChildren |
| 节点详情 | graphService | GET /getGraph?nodeId= | nodeId | currentNode |

## 4. 状态与存储

- **页面 data**：`{nodes:[], currentLevel:1, breadcrumb:[], loading:true}`
- **页面间传递**：nodeId（跳转详情页）

## 5. 微信能力使用

## 6. 生命周期钩子

| 钩子 | 动作 |
|------|------|
| onLoad | 调 getGraph() 获取根节点列表 |
| onShow | 无特殊处理 |

## 7. 错误处理

| 场景 | 处理 |
|------|------|
| 数据加载失败 | Toast「加载失败，请重试」+ 重试按钮 |
| 节点不存在 | Toast「节点不存在」+ 返回上一层 |
| 无子节点 | 不显示展开箭头 |
