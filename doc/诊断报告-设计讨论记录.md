## 一、报告的第一性原理

**核心哲学（用户明示 2026-08-15）**：让学生明白**为什么错**——这是产品存在的理由，不是手段。

**理解错误本身是目的**：学习、成长、不再犯。
「明白为什么错」→ 自然知道该做什么 → 成绩提高只是副产品（不是设计目标）。

**核心原理链**：
```
明白的三层：
  ① 错在哪（断点）——看见
  ② 为什么会错（根因）——理解
  ③ 自己领悟（顿悟）——内化
报告的全部设计服务于「明白」，成绩提高 = 明白的自然结果
```

## 二、报告的角色定位

**报告 = 单向、静态、≤3 分钟、让学生明白为什么错的启动器**

| 不是 | 是 |
|---|---|
| 答案的提供者 | **思考的启动器** |
| 双向对话 | 单向输出（双向 = 教练的活） |
| 数据报表 | 处方 + 钩子 |
| 命令执行单 | 可选任务 + 收获预告 |

## 三、报告的五层结构（每层含原理依据）

### ① 呈现断点
- 内容：过程走到哪一步断了（数据：归因 + P 过程分布）
- 不是「你错了」，是「你卡在分离参数后求最值这一步」

### ② 深挖根因（基于历史模式）
- 内容：这次错 + 历史同类也卡同位置 = **模式**；历史无同类 = 单次意外
- 原料 = RAG 30 天检索（时间窗 + 题型锚 + 置信度）
- 根因判断 = 假设 + 证据 + 程度化话术
  ```
  ❌「你的根因是题型缺失」
  ✅「问题可能出在『分离参数后求最值』这个套路
     （你上次也卡这 + 这次分离做对了但最后懵了）」
  ```
- 置信度低 → 不硬给根因，退回「呈现断点 + 留白」

### ③ 认知冲突（制造「为什么」）
- 内容：「你分离做对了，但为什么每次都在下一步停？」
- 原理：Piaget 认知冲突——现有认知结构被挑战 → 驱动主动重组
- 恰到好处的冲突：不羞辱、不否定，只是「不一致」的呈现

### ④ 留钩子（顿悟留给学生）
- 内容：递进问题链（2-3 问），**不回答**
- 原理：
  - 顿悟（格式塔）：碎片摆到「差一步」，学生自己重组
  - 自我解释（Chi）：默读自问 = 最强学习活动
  - 蔡格尼克：未完成的问题记得更牢
- **防依赖**：结论是学生自己得出的，不是工具给的 → 下次他会自己检查那个位置（能力内化）

### ⑤ 可选任务 + 可能收获
- 内容：想补的话 → 最小动作；做完你会获得什么
- 原理：自我决定论（自主感 + 价值感）+ 目标梯度
- **收获话术不能绝对**：
  ```
  ❌「做完这道题会变成你的送分题」（承诺结果）
  ✅「做完你会更清楚这类题的路数，下次能自己判断该求最值」
    （描述能力/视角，不打包票）
  ```

## 四、情绪设计（学业情绪）

**问题**：学生做错题后的情绪链 = 挫败 → 羞愧 → 焦虑 → 习得性无助

**报告的三个情绪任务**：

| 任务 | 机制 | 心理学 |
|---|---|---|
| 打破习得性无助 | 失败归因到「具体、可改变」的点（卡在一步，不是我笨） | Weiner 归因理论 |
| 恢复自我效能 | 先给能力证据（「你分离这步做对了」）再给行动 | Bandura 自我效能 |
| 失败具体化 | 「只差最后一步」vs「基本不等式不会」 | Seligman 乐观解释 |

**红线**：情绪设计必须基于真实数据（能力证据必须是真的）——无根据的鼓励摧毁信任。

## 五、治未病哲学

**诊断对象不是题对错，是「断点 + 根」**（决策 024）：

- 治已病：错题 → 练错题 → 下次同类还卡（补丁）
- 治未病：错题 → 找根因 → 重建根 → **预防扩散**（下次值域/含参分类不再卡）

**现状约束**：知识图谱只有 60 分（reference 覆盖不全），**不能靠图谱链做溯源**。
**正确路径**：从判定数据反推缺失（五维分数的内部矛盾）：
```
η 低 + P 高   → 做对但靠蛮力 → 题型缺失（A）
P 低 + D 低   → 简单题都卡 → 知识缺失（K）
P 高 η 高但答案错 → 执行失误（S）
```
图谱只做辅助定位，不做主推演。

## 六、Q 维度的边界

- 报告（单向）能做的：**触发** Q（留白、问题链、认知冲突）
- 报告（单向）不能做的：**完成** Q（追问、对话、引导说出）——那是学习教练（对话模块）的活
- 训练途径：报告留白 → 默读自问（单向内最大程度）；教练对话 → 完整引导（后续）

## 七、篇幅与内容（提高成绩导向）

**3 分钟三屏**：
| 屏 | 内容 | 依据 |
|---|---|---|
| 结论屏 | N 个薄弱点（≤3）+ 每点一行结论 | 认知负荷 4±1 |
| 计划屏 | 选一个薄弱点 → 断点/根因/钩子/可选任务 | 目标梯度 + 自我效能 |
| 证据屏 | 支撑题 + 30 天同类统计（可展开） | 结论看得见证据 |

**塞**：薄弱点结论（带证据）、可能根因、钩子问题、可选任务 + 可能收获、30 天同类统计
**不塞**：D/P/η 数值、五维雷达、归因长文、题目全列表、鸡汤
