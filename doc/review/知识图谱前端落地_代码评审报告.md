## 四、P1 修复详情（v1.0.0）

### 修复 1：onCrumbTap 面包屑裁剪

```js
// 修复前：const popCount = this._stack.length - (idx - 1);  // 多弹一层
// 修复后：
if (idx === 0) { this.enterSubject(); return; }
const popCount = this._stack.length - idx;
if (popCount <= 0) return; // 点击当前项，无操作
```

场景验证：节视图点节 → popCount=0 no-op ✓；节点视图点节 → popCount=1 回节 ✓；点数学 → enterSubject ✓。

### 修复 2：演化模式状态原样恢复

`enterEvo` 保存 `{ node, stack, kids: this._currentKids }`；新增 `_restoreFromEvo()`，`exitEvo`/`evoReturn` 统一原样恢复。合成节点的 kids 不再被重建清空。
