## 二、部署前提（客观事实）

### 环境变量（云函数）

`QWEN_API_KEY`、`DEEPSEEK_API_KEY`、`QWEN_BASE_URL`、`QWEN_VL_MODEL`、`DS_BASE_URL`、`DS_MODEL`、`EMBEDDING_MODEL`

### 运行时

Node.js **16.15+**（4 个云函数 package.json 已声明 `engines.node >=16.15.0`）

### 集合与索引

| 集合 | 索引 | 安全规则 |
|------|------|---------|
| questions | 复合 `batchId+userId`；复合 `userId+createdAt`(降) | `doc._openid == auth.openid` |
| batches | 复合 `userId+createdAt`(降) | 同上 |
| mastery_logs | 复合 `userId+createdAt`(降) | 同上 |
| knowledge_progress | 预建（P0 不写入） | 同上 |
| knowledge_nodes | 单 `knowledgeId`；单 `parentId`；单 `level` | 公开读 |

### 云存储

`photos/{userId}/` 目录（照片按 openid 隔离）
