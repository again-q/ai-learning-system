## 〇、先认错

我上一版写了一句：「难题不构成问题（班级 17% 那道你丢 12 分，但**全班都在丢**）。这不是你的短板。」

**这句话是错的，而且错得不该。**

它把「难题上丢的分不该计入你的短板」当成了推论。**但"全班都在丢"只说明这个题难，不说明它对你没有价值** —— 而且我用的样本是 **1 道题**，从 1 个点推出"难题不重要"。

**用户指出的才是对的**：对高分段学生，难题是**必须啃的部分**，不是可以排除的部分。高中数学的分差主要在难题上，中档题 Everyone 基本都会。

**所以正确的说法不是"排除难题"，而是"难题和中档题是两种不同的问题，需要两种不同的处理"。** 本文重做这个分类。

## 一、先清噪声：13 道"我 0 分"不是解答题

上一版统计时混进了 13 道 `officialScore=0` 的题，**全部是选择/填空题**（集合与命题、充分必要条件等），不是解答题。

它们和这次讨论**不在一个世界里**（选填没有过程、没有步骤分），排除后作者有效解答题 **10 道**。

**这条本身是个结论**：官方逐题分覆盖 23 道题，但其中 **13 道是选填** → **选填题只能判断对错，无法做过程审阅**。这从官方数据侧再次印证了 `TARGET.md` 的边界「过程审阅 = 只做解答题」。

## 二、按「我 vs 班级」重新分层（这是本轮的关键发现）

上一版只按难度排，得出"58% 档丢 18 分"。但**难度不等于问题** —— 有的题全班都会，你只是没发挥好；有的题全班都崩，你超出班级。

按 `我得分率 − 班级得分率` 分三层：

| 层 | 题数 | 丢分 | P 值 |
|---|---|---|---|
| **超常**（比班级高 15 个点以上） | 3 道 | 15 分 | 0.6 / 0.9 / 0.85 |
| **持平**（±15 个点内） | 4 道 | 20 分 | 0.3 / 0.85 / 1 / 1 |
| **失常**（比班级低 15 个点以上） | 3 道 | **27 分** | **0.5 / 0.3 / 0.3** |

**三个发现：**

### ① 失常的 3 道全在同一个难度档，全同一个错因

```
班级 58%  丢 9 分  P=0.5  结果错/rule  分段 通,通,断,通,通,断,断,断,断
班级 58%  丢 9 分  P=0.3  结果错/rule  分段 断,通,通,通,断,断,断
班级 58% 丢 9 分  P=0.3  结果错/rule  分段 断,断,断,断
```

**班级得分率全部 58%、丢分全部 9 分、错因全部 `结果错/rule`。** 这不是巧合 —— **同一类题、同一个环节、同一种错法。**

→ 这才是真正的主轴：**不是"58% 难度档"，是"这一类题我会在同一个地方崩掉"。**

### ② 超常的 3 道，P 也不算高

`P = 0.6 / 0.9 / 0.85` —— **都不到满分**。也就是说这三道题**我比班级好，但过程照样有断点**（分段全是 `通,通,通,断`）。

→ **"我做得好"和"我过程没毛病"是两件事。** 上一版说做对的题只丢 1、3 分，那是因为**那两道题简单**（班级 88%/80%），不是因为"做对所以过程好"。

### ③ 难题那一格：唯一一道题，不能下结论，但**不能排除**

| | 数值 |
|---|---|
| 班级得分率 | 17%（全班 80% 做不出） |
| 我 | 2/14 = 14% |
| 差 | −3 个点 → **基本持平** |
| P | 0.3，分段 `断,断,断` |

**这道题的性质和中档题完全不同：**

| | 中档题（58%） | 难题（17%） |
|---|---|---|
| 我丢分 | 9 分 | 12 分 |
| 丢的原因 | **同类题反复踩同一个坑** | **整道题没做出来**（`断,断,断` 开头） |
| 该给的东西 | 「你这个环节又错了」 | **「这类题怎么下手」** —— 现在完全没有 |
| 能不能靠练回来 | 能，方法是稳定的 | **不能，靠练没有用，需要新的方法** |

**我上一版说"难题不是你的短板"，错在把"练不出来"和"不重要"混成了一件事。**

对高分段学生，难题的意义恰恰在这里：**中档题决定下限，难题决定上限。** 但难题需要的不是"审阅自己写错的过程"（因为压根没写出来），而是**"看懂别人怎么解出来的"** —— 这是完全不同的产出。

## 三、所以报告要分两条线，判据完全不同

这是本轮的核心结论：**我上一版把它们放进同一个排序里，是错的。**

### 线 A · 中档题（保住不丢的）—— 我**会**但**没做全**

**判据**：我得分率 < 班级得分率（失常）
**现状**：3 道，丢 27 分，全部同一错因

**要给什么**：
- 定位到**环节**（不是知识点）："这类题你都在第 1 步之后崩"
- 跨题对齐：「同一类题 3 道，全在同一步」
- 改法要**具体到动作**：「这类题先做第 1 步就能看出后面要分类讨论」

**因为** 这是**可练的**问题 —— 方法是稳定的，只是没执行到。

### 线 B · 难题（往上啃的）—— 我**不会**

**判据**：班级得分率很低（< 30%）**且**我分段开头就断（`断,断,断`）

**要给什么**（和现在完全相反）：
- **不是**评判，是**示范**：把标准解法一步步摊开，标出「第一下手在哪」
- 讲**为什么第一手这么下**（这是"方法"，不是"答案"）
- 承认**这道题现在啃不动**，但给出「先啃哪一步」—— 让它变成可下手的子题

**因为** 这是**不可练**的问题 —— 靠重复做同类题没有用，缺的是方法认知。

### 现在的系统对这两条线的处理

| | 现在 | 问题 |
|---|---|---|
| 线 A | 给三段诊断（过程点评/问题在哪儿/下一步） | 没跨题聚合 → 「3 道题同一个坑」这个最有价值的信息丢了 |
| 线 B | 同一套三段诊断 | **结构上无法表达**。`diagnosis.txt` 的 prompt 里有「不归因」「不点破答案」的硬约束 —— **它被设计成不能说"这题该这么下手"** |
| 分类 | 两者都按 `errorType: 结果错` 处理 | **没有"我会不会"这一维** |

**最关键的一条**：`prompts/diagnosis.txt` 写着「禁止出现任何解题关键线索（不写"0次方等于1""令指数为0"这类点破答案的提示）」。

**这条约束对线 A 是对的（我做了对的事，别把我搞混）。**
**但对线 B 是致命的 —— 难题上不点破，他就永远学不到方法。**

**这是现成的、必须拆的一条约束，不是新功能。**

## 四、修正后的报告结构

上一版是「按失分总量一个排序」。**现在改成两条线 + 一个缺口提示**：

```
┌─ 保住：中档题失分（3 道，丢 27 分）──────────┐
│ ⚠️ 集合/命题这类题，你在同一个地方崩了 3 次     │
│    → 三道都是第 1 步之后就断了，根因都是 rule  │
│    [对照：3 道题并排看同一个环节]               │
│    改法：这类题先判断题干在问什么，再动笔        │
└────────────────────────────────────────────┘

┌─ 啃上去：难题（我基本做不出）────────────────┐
│ 📌 这道题全班 80% 做不出，你现在拿 2 分         │
│    标准解法第一步是 ______                    │
│    为什么第一步这么想：______                  │
│    先只啃这一步：这题第一步等价于「______」     │
└────────────────────────────────────────────┘

┌─ 稳住：做得好的地方（3 道超常）────────────┐
│ 这 3 道你比班级高 20 个点                       │
│ 不过过程也有断点——见上面第一条的环节            │
└────────────────────────────────────────────┘
```

**关键变化**：难题区**不是**"你做错了"，是"你先啃第一步"。**它不计入你的失分，它是你的上限在哪。**

## 七、两个问题

### Q1：难题这块，你想要什么？

我从数据只能推出"难题上我完全没过程可审"。**但你想要的是什么，有几种可能，方向完全不同**：

- **A. 讲第一下手** —— 难题不评判，只讲"从哪下手、为什么"，把它变成可下手的子题
- **B. 讲思路来源** —— 讲这类题的通用解法框架（可能更适合成体系）
- **C. 讲为什么该放弃** —— 教你在考场怎么权衡，先拿该拿的分（**如果你的定位是稳分而不是冲分**）
- **D. 不做难题** —— 只服务中档题，难题交给学校/教辅

**这四个的报告形态完全不同，代码也完全不同。** 我倾向 A，但你得定。

### Q2：那 3 道"超常题"（P=0.6/0.9/0.85），你自己觉得过程有问题吗？

这决定一个**范围问题**：报告要不要审"做得好但过程有断点"的题。

- 你觉得**有** → 要审，那报告范围是**全部解答题**
- 你觉得**没有**（模型判严了）→ 那 `segments` 的判定精度本身就是个 bug，得先修它

**这个不问清楚，报告的覆盖范围定不下来。**
