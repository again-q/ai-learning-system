## 三、从这 12 份里活下来的东西

归档不等于全部作废。以下是**已被现行版吸收**的关键结论：

| 结论 | 现在在哪 |
|---|---|
| **「标准可能是错的」** | 现行版 §一（报告不能依赖单一标准答案） |
| **「只跟自己比」** | 现行版 §四（设计原则 5） |
| **三件事的顺序**（发现缺失→原来这里错了→知道该补什么） | 现行版 §一 |
| **差异必须落到"行" + 附"凭什么"** | 现行版 ③ 段 |
| **「我不服」是地基** | 现行版 ③ 段 |
| **不做对的题也看不见"少写"** | 现行版 §一 |
| **文字要短、认知负荷两层** | 现行版 §四（原则 5） |
| **空白禁令**（不写"未理解"） | 现行版 §四（原则 2/3） |

**一句话：方法论层面活下来的很多，而具体结构（`r`、坏/松/绕、五维收敛为三维）全部被推翻。**

## 四、为什么保留而不是删除

```
① 它们记录了"为什么推翻"
   下次若有人提"为什么不用 r"或"为什么不分坏/松/绕"
   → 这里有完整的理由

② 有些结论是"部分存活"（如"标准可能是错的"）
   原文的论证过程有价值，结论只是搬了地方

③ 项目规范要求「只追加不改史」（决策 016）
   作废的稿加声明保留，而不是删除
```
