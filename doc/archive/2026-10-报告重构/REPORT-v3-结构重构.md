## 0. 一句话

**报告现在的主轴是「题」，新报告的主轴是「差异」。** 五维里 **S（执行稳定）是「松」的现成落点**——它不该继续"未实现"，该升 P0。

## 1. 现状：报告实际长什么样（实查）

### 1.1 存储结构 —— 报告是「索引」，诊断在另一张表

线上 `reports.report` 只有 4 个字段（33/33 份全覆盖）：

| 字段 | 类型 | 实测内容 |
|---|---|---|
| `summary` | string | 「11道题做对了10道，全对的题都很扎实，继续保持这个节奏就行。」 |
| `masteryChange` | 数组 | `{nodeId, name, before, after}` |
| `pendingNodes` | 数组 | 5 条 |
| `questions` | 数组 | **每题仅 6 字段**：`questionId / questionText / status / questionType / pattern / knowledgeNames` |

**关键断层**：`report.questions[]` 里**没有诊断文字**。三段诊断写在 `questions.diagnosis`，覆盖 **49/61**，格式 `{comment, inference, hook}`。前端点开某题时调 `reportService?action=questionDetail` 二次拉取（`index.js:339-357`）。

→ 报告对象本身**不能独立渲染**，必须配一次 `questionDetail` 往返。这是 v3 要收掉的结构债。

### 1.2 页面结构（`report.wxml` 实读，自上而下）

```
分数 + 圆点阵 + summary          ← 批次级
逐题深读（每题可展开）
  ├ 题目
  ├ 你的过程（照片 + segments 逐段 ✓/✗）
  ├ 过程点评 / 问题在哪儿 / 下一步     ← diagnosis 三段
  ├ 题型（可异议）
  ├ AI 参考过程（可异议、可重生成）
  └ 进阶分析（同类题趋势）
掌握度变化                       ← 知识点 before → after
```

### 1.3 与目标的距离

| TARGET.md 要求 | 现状 | 差距 |
|---|---|---|
| 我的过程 ‖ 标准过程**并排** | 你的过程在上、AI 参考过程在下，**两张卡分离、无步骤级对应** | 🔴 核心缺口 |
| 三类差异（坏/松/绕） | 只有 `segments.status` 的 `通/断/空白`；`errorType: 过程风险` 5 道 | 🔴 「松」「绕」为零 |
| **对做对的题也审阅** | 逐题深读对**全部题**开放 ✅；但「你的过程」卡 `wx:if` 有 `segments` 才显示 | 🟡 做对的题多数无过程可展示 |
| 跨题动作对齐 | 只有知识点级（`masteryChange` / `knowledgeNames`） | 🔴 无动作维度 |
| 五维呈现 | **一个都没有** | 🔴 见 §2 |

## 3. 🔴 核心发现：「松」不用新造，S 维度就是它的位置

决策 052–057 那轮把 K/A 的公式重写了一遍，但**「松」这个信号一直悬着**（`TARGET.md` §10 未决 #1）。现在有答案了：

> **「松」＝ 结论对但过程不严谨 ≈ S 维度（执行稳定）要抓的那个东西。**

依据在你自己项目的待办里（`doc/掌握度链路-待办.md:20`）：

> **S 维度未实现**：失常信号（**P 高但答错，如 P 0.8~0.95 且归因执行类**）无处归档。公式现成：`S0 = |P_exp − R_actual|`

`S0 = |P预期 − R实际|` 就是「差多少分算松」的度量。而它至今是 🟡 中优先级、"公式现成没人做"——**因为旧目标下没有信号源；新目标下有了：高分学生做对但过程松的题，正是这批人丢分的全部原因。**

**处置：S 从「🟡 中优先级未实现」升 P0 主信号。** 这比新造一个 `segments.status: 松` 档更省——公式、字段、落库口径都现成，只差接线。

## 4. 报告 v3 结构设计

### 4.1 主轴从「题」换成「差异」

现在：题列表 → 逐题展开 → 每题内部再解释。
v3：**先给差异清单，再回溯到题**。

理由（从目标推，不是从模型推）：高分学生的痛点 3 是「**重复的错自己抓不住，因为每次遇到都当新问题**」。题列表天然把这个信息销毁了——同一处松 5 次，在 5 个折叠面板里显示 5 次。

### 4.2 v3 骨架

```
┌─ 批次头 ────────────────────────────────────────┐
│  这批最值得改的 3 处                    （不再是分数）│
│  · 跳步：解「含参对数」时未写定义域        出现 4 次 │
│  · 省略：代入后未化简到底                  出现 2 次 │
│  · 绕：分类讨论用了 3 段，标准解法 1 段      出现 1 次 │
└────────────────────────────────────────────────┘

┌─ 按「动作」聚合（跨题对齐）─────────────────────┐
│  动作卡：跳步 · 定义域                            │
│   跨 4 道题出现，其中 2 道丢分                    │
│   [题A ✓对照] [题B ✓对照] [题C ✓对照] [题D ✓对照]  │
└────────────────────────────────────────────────┘

┌─ 步骤级并排对照（每题展开）─────────────────────┐
│  步骤  │ 你的过程        │ 标准过程      │ 判定   │
│  1     │ 写出 a>0        │ 写出 a>0      │  一致  │
│  2     │ 对数求值        │ 化为指数形式  │  松 ⚠  │  ← 最大价值
│  3     │ （跳过了定义域） │ 补充 a≠0      │  坏 ✗  │
└────────────────────────────────────────────────┘

折叠区：AI 参考过程（已标注来源）｜题型异议｜过程异议｜进阶分析   ← 全部保留现有能力
```

### 4.3 三类差异的判据（可直接落地）

| 差异 | 判据 | 复用现成信号 |
|---|---|---|
| **坏** | 结论错，或存在 `segments.status='断'` 且该步是根因 | ✅ 已有（19 道） |
| **松** | 结论对，但存在 `S0 = |P_exp − R_actual| > 0` 的步骤 | ✅ **S 公式现成**，只差接线 |
| **绕** | 结论对，步骤数 > 标准解法步骤数 × 阈值 | ⚠️ 需 `referenceProcess` 步骤数比对（49/61 有，够用） |

**「绕」的判据要你先认一条**：绕不一定是错的（有时标准解法更慢）。建议阈值先按「多了 ≥2 步且不更稳」触发，标为**提醒**而非**扣分**。

### 4.4 数据契约变更（v3 必须动的）

| 变更 | 说明 |
|---|---|
| `report.questions[]` **内联诊断** | 消除二次拉取；`questionDetail` 降级为兜底（向后兼容，老报告照读） |
| 新增 `processAlignment[]` | `{qid, myStep, refStep, verdict: 坏\|松\|绕\|一致, note}` |
| 新增 `actionClusters[]` | `{action, occurrences[], lostCount, samples[]}` —— 跨题动作对齐的落点 |
| `masteryChange` **降级** | 折叠到末尾，K 变副指标后不值得占首屏 |

## 5. 五维处置裁决

| 维度 | 现状 | 裁决 | 依据 |
|---|---|---|---|
| **K** 知识掌握 | 已实现（052 新口径 `attempts/correctCount`） | 🔻 **降副指标**，折叠到报告末尾 | 高分学生 K 饱和、区分度≈0；且 `kFormula` 只统计**叶子**行（`aggregated!==true`），本身是练习量口径而非能力口径 |
| **A** 熟练度/难度分层 | 已实现 | 🔺 **升主指标** | 高分学生的全部区分度在难度层：简单题全对、难题失手。A 是唯一能表达"他在哪种难度上失手"的维度 |
| **S** 执行稳定 | **未实现**，公式现成 | 🔺 **升 P0 主信号** | §3：「松」的现成落点；高分学生丢分主要在这里 |
| **Q** 思维品质 | 未实现，数据源需思维链 | ⛔ **不做** | ① 撞决策 048 采集冻结（零新增）② 撞「不需要学生主观输入」③ **你的思维方法不是被评估对象**（`TARGET.md` §1.2） |
| **T** 迁移能力 | 未实现 | ⛔ **推迟** | 需跨单元综合题作输入；必修一图谱够用但样本量支撑不了（`TARGET.md` 已定必修二~五推迟） |

**净结果：五维 → 三维。** K（副）+ A（主）+ S（主信号）。Q/T 明确不做。

**顺带必须处理**：线上 `qOverall=0.55 / sOverall=0.68 / tOverall=0.45` 三个**无来源的数字**。要么查清来源，要么清零——**不能让假数字在重构后被当真数据读**。这是本次重构的前置动作。
