## 二、五维模型工程规格

- [x] ✅ K 维度：加权得分法 Sₖ/Dₖ — 已定稿（理论文档 §4）
  - LLM 判难度（5 维：知识复杂度、思维深度、陷阱密度、计算强度、陌生度），范围 0.01~0.99
  - LLM 判定过程分 4 档（1.0/0.5/0.3/0）
  - 掌握度 = Σ(D×P) / Σ D
  - 4 档制：≥0.80 掌握 / 0.60~0.79 巩固 / 0.40~0.59 薄弱 / <0.40 紧急
  - 待做：工程实现云函数（LLM 判难度 + 判过程分 + 聚合计算）

- [x] ✅ A 维度：A/U 框架 + η 路径质量 — 已定稿（理论文档 §5）
  - 有效刺激量 E = D × η
  - A 在 [0, U] 内受 E 驱动更新，U 随本质解法上浮/暴力计算下浮
  - 粒度：每单元一个 A + 全局聚合
  - 待做：工程实现云函数

- [x] ✅ T 维度：W×D×r + T/U 框架 — 已定稿（理论文档 §6）
  - W（跨类型权重）：课内跨单元 0.60~0.80 / 跨学科 0.50~0.60 / 初中跨高中 0.30~0.50
  - r（解题质量系数）：0~1，LLM 多轮引导后评分
  - 待做：工程实现云函数

- [x] ✅ Q 维度：Flavell 元认知，5 子维度 — 已定稿（理论文档 §7）
  - Q1 事中监控 / Q2 归因准确度 / Q3 调整清晰度 / Q4 反思深度 / Q5 执行结果
  - 聚合公式：Q = 0.25×Q1 + 0.25×Q2 + 0.25×Q3 + 0.15×Q4 + 0.10×Q5
  - 待做：弹窗交互 + LLM 评分 prompt

- [x] ✅ S 维度：S0 波动 + S1~S6 失常 — 已定稿（理论文档 §8）
  - S0 算法：预期得分率 P_exp = w_K×K + w_A×A + w_T×T，d = |P_exp - R_actual|
  - S_global = 0.6×Self_stability + 0.4×Obj_stability
  - 待做：工程实现云函数
