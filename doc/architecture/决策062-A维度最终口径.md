## 一、定义

> **A = 在一个单元里，「已知要用哪个知识点」之后，他把步骤做完做对的程度。**

## 二、完整算法

```
记账粒度：每个 (学生 × 单元) 一条记录
          单元 = 知识点在教材图谱里的 path[2]
          存四个数：A、U、W、S     （W = Σw，S = Σ(w·s)）

一道题进来：

  ① 空题跳过
     processAvailable = false   →   跳过，A/U/W/S 都不动

  ② 权重（难度进 A 的唯一入口）
     w = D
     例外：D ≥ 0.94（L10–L11 超纲）→  w = 0，完全不计入

  ③ 观测值
     s = P                     P = 模型判的过程分（0~1）
                               难度不再给分数打折

  ④ 更新 A（累计加权平均 + 弱先验）
     W ← W + w
     S ← S + w · s
     A = (w₀ · A₀ + S) / (w₀ + W)
         A₀ = 0.30      w₀ = 1

  ⑤ 更新 U
     连续 2 次 s > U   →   U ← U + 0.05 × (1 − U)
         U₀ = 0.50       U 只涨不跌
```

**为什么权重是 D 本身**：`D难度标尺` §十 原话 ——「D 是五维更新的乘法因子（**K = Σ(D×P)/ΣD** 等）」。**D 当权重、不当折扣。**

### 已删除的五项

| 删掉 | 原因 |
| :--- | :--- |
| `q = 1 − 断段数/总段数` | 输入（segments）已撤；实测段数不一致率 62%、Δ段数最大 8 |
| `errorLevel !== 'skill'` 闸门 | 线上 89% 判不出；且算错按定义本就该进 A |
| U 下浮（连续 5 次 s ≤ 0.6） | 绝对门槛是旧校准的产物，实测几乎不触发 |
| 上浮门槛 `s ≥ 0.8` | 绝对门槛把新手锁死（s=0.35 永远够不到） |
| 三因子相乘 `ΔA = 0.25(s−A)(U−A)` | 乘 `(U−A)` 会让 A 早早贴住 U 后动不了；三因子也无依据 |

## 三、读法

> **A × 100 = 他做过的题里，按题目难度加权的平均过程完成度**

- **上限 = 100**（难度不打折，满分就是满分）
- **下限 = 0**
- **权重 = D** → 越难的观测话语权越大（D=0.5 权重 0.5，D=0.75 权重 0.75，1.5 倍）
- **超纲题（D ≥ 0.94）权重 0** → 彻底不影响 A

## 七、⚠️ 空题必须排除

```
空题 = 学生压根没写（processAvailable = false, P = 0）
算成 0 分  →  等于判定「他没做 = 他不会」
而这正是 diagnosis.txt 明令禁止的一条：「没做不代表不会」
```

**现行代码等于对 9 道空题下了 9 次判决，全部按「不会」记账。**
**这一条是纠错，不是调参 —— 贡献了 +29 点。**
