## 核心原则

> **定性归 AI，定量归代码。** AI 只出定性结论（题型分类/证据/技术标签/原始信号），数值全部由代码执行公式。

```
三门禁路由（在第三阶段 Flash 内）：
  门禁1 题型分类 → 回忆类 / 单元内应用 / 跨单元应用 / 无法归类
  门禁2 标准答案路由 → 三层降级（见「无答案题三层流程」）
  门禁3 归因路由 → AI 输出证据+技术标签 → 代码映射至五维
```

## 六阶段流水线

### 第一阶段：数据采集（小程序端）✅ 架构已定

```
输入：学生拍照/选图 +（可选）口述上传 +（可选）手动录题
处理：存储 globalData.currentContext → 上传至云存储
输出：imageFileId + studentNarration + sourceType
```

### 第二阶段：图像理解（Qwen3.7Plus）✅ 模型已定，API 可调

```
输入：原始图片（题目 + 学生笔迹/草稿/涂改/停顿位置）
处理：多模态识别 → 输出 Markdown 报告
输出：①题目文本（含公式/图表）②做题痕迹描述（涂改/停顿/草稿）
```

### 第三阶段：核心推理与归因（DeepSeek V4 Flash）🟡 归因证据链待细化

```
输入：Markdown 报告 + 历史五维数据 + RAG 检索（top-5，暂缓）

【门禁1：题型分类】→ 回忆类 / 单元内应用 / 跨单元应用 / 无法归类
【门禁2：标准答案路由】→ 三层降级（见第五节）
【门禁3：归因路由】→ AI 输出证据+技术标签 → 代码映射至五维

输出（AI 定性层）：①技术标签 ②错因描述 ③原始信号（P, D, η, r, Q1~5）
状态：🟡 归因证据链待细化（M8）；System Prompt 待写
```

### 第四阶段：数值计算（代码执行层）✅ 公式已定，代码照着敲

```
输入：AI 输出的原始信号 + 历史库数据
处理：代码执行五维公式（记号：下列为增量/终值，勿把 Δ 写成状态本身）
  K：掌握度 = S_k / D_k（加权得分法；⚠️ 触发时机见 M4，未拍板）
  A：E = D × η；ΔA = 0.25 × E × (U − A)；A ← clamp 至 [0, U]（A/U 框架）
  T：先更新 TU，再 ΔT = 0.20 × (T_shown − T) × (TU_new − T)；T ← clamp 至 [0, TU_new]
  Q：Q_i 移动平均后 Q = 0.25Q1+0.25Q2+0.25Q3+0.15Q4+0.10Q5（引擎侧待落，见 M6）
  S：S_global = 0.6×Self + 0.4×Obj（引擎侧待落，见 M7；S0 可先算）
输出：五维数值 + 置信度标记
```

### 第五阶段：Q & S 维度工程化 🔴 当前最大黑盒，待细化

```
【Q 维度 - 思维链采集】
  触发：高价值题目判断（做错/过程复杂/关键节点）
  频次：30 分钟内 ≤2 次，每天 ≤5 次
  ❓ 待设计：弹窗时机、Prompt 话术、Q1~Q5 评分锚点（M6）

【S 维度 - 失常回溯】
  S0 客观波动：代码自动算 ✅ 公式已有
  S1~S4 主观回溯：依赖思维链中的回溯环节
  ❓ 待设计：如何区分 S1 计算问题 vs K 知识问题的 Prompt 逻辑（M7）
```

### 第六阶段：诊断报告生成 + 数据持久化 🟡 结构定稿，归因层待细化

```
输出结构（五层报告）：
  ① 本次结论（错因 + 知识点定位）
  ② 模式识别（跨题找规律）
  ③ 行动建议（MIT 最小干预指令）
  ④ 趋势（正确率曲线、五维变化）
  ⑤ 归因（贯穿，待细化）

写入：questions + mastery_logs（含五维快照+算法版本）
RAG：embedding 存 mastery_logs（暂缓，confidence ≥ 0.7 同版本）
```

## 四、理论基础（五维公式均源自理论文档）

> 全部公式与参数表见 `doc/theory/五维能力向量框架-理论文档.md`（4.4/5.5/5.7/6.5/7.6/8.4-8.5）。

| 维度 | 公式 | 关键参数（AI 结合理论文档生成） |
|------|------|------|
| K | 掌握度 = S_k/D_k（加权得分法；非 BKT）。**触发时机未拍板**（见 M4） | D（难度 5 维）、P（过程分 4 档） |
| A | E = D×η；ΔA = 0.25×E×(U−A)；A/U 框架（理论 §5.5） | D、η（路径质量 0.4~1.0）、U 上浮/下浮、做错时 E 符号 |
| T | E_t = W×D×r；ΔT = 0.20×(T_shown−T)×(TU_new−T)（理论 §6.5） | W、r（0~1）、T_shown、TU 更新规则 |
| Q | 理论 §7.6 已有；引擎 scoreFiveDim 本阶段未落（M6） | Q1~Q5 评分锚点、弹窗概率 base_prob |
| S | 理论 §8.4–8.5 已有；引擎本阶段未落总分（M7）；S0 可先算 | 失常率 S1~S4、波动指数 V（N=20~30） |

**核心难点（M3）**：公式已全，但**参数由 AI 结合理论文档跑出**——D/η/W/r/T_shown 等每个都是 LLM 判定，判定质量直接决定评分质量。用全链路指导查缺，逐参数验证。

## 五、无答案题三层流程（对应门禁2 的三层降级，决策 011）

```
【第一步】AI 判可解性（不看学生答案）
    ├─ 能（有确定答案）→ AI 算标准答案 → 进入维度更新（⚠️ K 是否更新见 M4；A/T：单元内→A，跨单元→A+T）
    └─ 不能（主观/无确定解/图形残缺）→ 进第二步

【第二步】放弃对错标记，只做过程诊断
    ├─ 分析学生步骤 → η（A，路径质量 0.4~1.0）+ r（T，解题质量 0~1）
    ├─ 更新 A（单元内题）或 T（跨单元题）；K 冻结不更新（草案）
    └─ 触发思维链弹窗，重点采集 Q 维度

【第三步】S 维度轻量自评
    └─ 弹窗「这题你觉得能拿几分？」→ 比对 AI 过程分析 → 稳定性报告
```
