## 一、报告定位

> 报告 = **仪表盘**（趋势）+ **处方**（错因 + 行动）

- 趋势是报告的仪表盘——它验证结论、让进步可见，但它**不是主体**
- 主体是处方：本次错因 + 跨题模式 + 下一步行动
- 诊断不落到行动 = 没有诊断（工具定位：课后辅助诊断，不代替学校）

**第一性原理推导：** 真正学好 = 知道自己具体哪里不懂 + 知道明天做什么。从结论倒推出报告结构。

---

## 二、报告五层结构

| 层级 | 内容 | 为什么必须有 |
|------|------|------------|
| **① 本次结论（核心）** | 每道题的错因 + 定位到具体知识点 | 没有它，报告只是一堆数字，学生看完不知道问题在哪 |
| **② 模式识别** | 跨题找规律：连续错的同类题、反复出现的错因 | 学习最大的敌人是「每次错得不一样」——模式才是可打击的目标 |
| **③ 行动建议（灵魂）** | 下一步练什么：补哪个知识点、做哪类题、怎么练 | 诊断不落到行动 = 没有诊断。建议是「课后补哪里」，不是讲课 |
| **④ 趋势（证据 + 激励）** | 同类题正确率曲线、五维变化折线 | 验证①②不是偶然，同时让进步可见 |
| **⑤ 归因（贯穿）** | 错是「不会」还是「粗心」——两者对策完全不同 | 归因错，练习就白做。这是 Q 维度的核心 ⏳ **待细谈** |

---

## 三、趋势的定位与用途

**单独看正确率趋势，价值有限** —— 它是结果指标，不是学习指标。学生可能正确率稳定上升，但只是记住了题型套路。

**趋势真正值钱的三个用途：**

1. **验证结论，不是下结论** — 单次诊断说「分式化简薄弱」可能只是巧合（题难/状态差）。同类题连续 3 次错在同一处，才是真薄弱点。趋势让结论从「猜测」变「证据」。
2. **检验学习有效性** — 练了一周，趋势能否证明「练了有用」？K 维度涨了没、是否沉淀。K 按加权得分法（S_k/D_k）累计难度×过程分，趋势来自 mastery_logs 快照，不是 BKT。
3. **激励** — 进步可视化是维持学习动机最强的工具之一。「同类题正确率 30% → 65%」比任何口号都有用。

**技术前提：** 五维评分本身必须可靠，否则趋势是噪音。趋势至少积累几次诊断才有意义——首次使用报告时可能只有一条线，PRD 需写明此预期。

## 五、行动模块：补缺漏计划（③层，2026-07-30 细化）

### 5.1 架构定位（澄清）

- **诊断报告 = 完整的自我服务包，不依赖 AI 教练**：报告自带可执行的补缺漏计划（补知识点/练什么/顺序/完成标准），学生可直接执行
- **AI 教练 = 系统内置的一种「实现建议的方式」，但不是唯一**：
  - 诊断引擎报告是 AI 教练的**其中一个入口**（可选按钮），不强制
  - 学生可以直接进教练对话（不一定要先诊断）
  - 报告自带完整补缺漏计划，不依赖教练
- **行动模块三层结构**：
  | 层 | 谁 | 输出 | 时机 |
  |----|-----|------|------|
  | 触发层（报告③） | 诊断引擎 | 补缺漏计划（静态，自足可执行） | 报告内 |
  | 对话层（AI 教练） | 学习教练 Agent | 对话式深化引导（可选入口） | 学生点选时 |
  | 巩固层（趋势） | 系统 | 执行结果回写 → 下期诊断验证能力建立 | 持续 |

### 5.2 设计依据（参照技术书精华，取意不取名）

| 技术书精华 | 应用到补缺漏计划 |
|-----------|----------------|
| 第8/9章 依赖溯源 | 补**前置卡点**，不补表面错点：沿知识依赖链上溯到真正卡住的那一环 |
| 第16章 题目研判 | 精准对症：补「长度单位关系不清」就补单位理解，不盲目「多做小数题」 |
| 第17章 题目攻坚 | 练习落到**具体卡点**：不说「这题太难」，说「卡在第二步不知道如何简化」 |
| 第9章 终点类型 | 上溯有终点：定义/公理/约定/实用终点，不追到宇宙尽头 |

### 5.3 补缺漏计划生成算法

```
输入: 错题 + 归因结果 + 知识图谱
   ↓
① 定位: 错题关联的知识点 B（门禁1 输出）
   ↓
② 上溯: 沿图谱依赖链 B → 前置 A1 → A1 的前置 A2 → …（第9章溯源）
   ↓
③ 找卡点: 检查链条上每一环的掌握度，第一个 < 阈值 的就是真正卡点
   （例: B=分类讨论 掌握 0.7，A1=因式分解 掌握 0.4 → 卡点在 A1）
   ↓
④ 定计划: 对卡点 A1: 补什么 / 怎么补 / 顺序 / 完成标准（第16章研判）
   ↓
⑤ 输出: 补缺漏计划 = [卡点 → 动作] 一对一清单，不盲目刷题
```

### 5.4 补缺漏计划 v2（含行为设计）

**认知科学三原理（让人看了真有行动欲望）：**

| 原理 | 机制 | 效果 |
|------|------|------|
| 目标梯度效应 | 分段 + 进度可视化 | 持续动力：看到进度在动而非「5件事待办」 |
| 自我效能 | 每步即时判定过/不过 | 做完立刻知道对不对，不盲练 |
| 最小承诺 | 今日一步 = 5 分钟微动作 | 降低启动门槛，先跨出最小一步 |
| （贯穿）自主感 | 可选：教练/图谱 | 学生有选择权，不被推着走 |

**输出格式：**

```
📋 补缺漏计划
├─ 根因: 分类讨论不牢 → 真正卡点: 因式分解（前置，掌握度 40%）
├─ 进度: [● ● ○ ○ ○] 2/5 步
├─ 今日一步（5分钟）: 默写因式分解公式，对照错题找卡点
├─ 然后: ①重做3道基础（做完对答案，2/3过）②变式: 含参分类 ③回到原错题重做
├─ 完成标准: 原题独立做对 + 同类 2/3 对
└─ 可选: [找 AI 教练带] [看依赖链]
```

### 5.5 关键设计点

- 计划指向**前置卡点**（依赖溯源），不是表面错点
- 每个薄弱点给**精准动作**，不给「多刷题」
- 练习建议落到**具体卡点**（难点要具体才能对症）
- 上溯**有终点**（定义/公理/约定/实用终点）
- 计划**自足可执行**，教练是可选深化通道

## 六、待细谈：归因模块（⑤）

- 归因不只是「不会 vs 粗心」——可能还有：概念混淆、计算失误、审题错误、方法不当、状态波动
- 归因决定行动建议的对策，是 Q 维度（思维品质）的落地接口
- 归因粒度：每道题归因 vs 跨题归因模式
- 归因来源：学生自述（点对错时补充）vs AI 从做题痕迹推断 vs 两者结合
