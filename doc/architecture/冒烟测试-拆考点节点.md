## 1. 目的与范围

验证"题面 → 考点清单"（拆考点节点：识别章 → 系统按章取候选 → AI 勾选考点）这条链能端到端跑通、输出符合契约。**冒烟 ≠ 质量验收**：只回答"能不能跑、契约对不对、有没有灾难性失败"；"拆得全不全、难度准不准"属正式评测（环境就绪 + 真实题面金标准后另立）。

## 3. 拆考点节点规格（被测对象）

**归属**：诊断（判定）流水线内的一个节点（题侧链第一环），不是报告阶段动作；内部本身是一个小图（模型→代码→模型）。

```
输入：题面文字
① 模型：识别涉及哪些单元（1~N，宁宽勿漏）
       —— schema 枚举约束：从章名表（5 章）多选，输出 {"chapters":[...]}
② 代码：getPointsByChapter(单元) → 逐单元取候选（确定性；章=path[2]；只留知识点叶子）
       —— 纯代码，无模型；检索可并行，但呈现/选择严格逐单元
③ 模型：逐单元勾选——一次只呈现【当前单元】候选，不跨单元混排
       输出 = 编号（pointIds + dkps），不抄名字；代码查表还原为知识点名并校验 ∈ 候选
       候选都不符 → 「其他」：必须 依据 + 五要素命名 双门槛，缺一不可（缺则违规）
输出：考点清单 [{考点, 所属章, D_kp}] + 超纲标记 + 其他[]
入选判据：不掌握它，本题就可能做错
字段语义：D_kp = 纯考察难度（0~1，题内相对可比），无比重含义；
「其他」→ 云端待审池，学生端不显示，审核通过前不参与掌握度累计
```

**模型输出 schema（步①/步③）**：

```json
① {"chapters": ["第一章 集合与常用逻辑用语"]}   // 只能从 5 章名表多选
③ {"pointIds": [3, 12], "dkps": {"3": 0.8, "12": 0.4},   // 编号 ∈ 当前候选
   "other": [{"name":"","elementType":"定义|表示|性质|操作|关系","reason":"依据"}],
   "outOfSyllabus": false}
```

**代码防线**：编号还原后的名字不在候选 → 不算 points，自动转「其他」并检查双门槛；跨单元编号不混排（每次选择只含当前单元，编号本单元内 1~N）。

## 4. 测试集（合成题面，8 条）

| 题 | 分支 | 题面 | 对照预期（人看，不喂模型） |
|---|---|---|---|
| T1 | 单章·单考点 | 已知集合 A={1,2,3}，B={2,3,4}，求 A∩B | 第一章；集合交集 ≈1 考点，D_kp 中 |
| T2 | 单章·多考点 | 解不等式 x²−5x+6>0，并把解集用区间表示 | 第二章；≥2 考点（二次不等式解法+区间表示），主>次 |
| T3 | 跨章 | 求函数 f(x)=√(x−1)+1/(x−2) 的定义域 | ≥2 章（函数定义域 + 不等式/区间表示） |
| T4 | 隐性考点 | 已知 f(x)=x³−3x，判断奇偶性并说明理由 | 第三章奇偶性；隐性：定义域对称/幂运算 |
| T5 | 边界陷阱 | 若集合 A={x \| ax²+2x+1=0} 恰有一个元素，求实数 a | 第一章；陷阱 a=0 退化与 Δ=0 分类 |
| T6 | 回忆类 | 默写分数指数幂运算性质（≥2 条）并说明底数 a 的取值范围 | 第四章；纯知识回忆，含底数边界 |
| T7 | 候选外 | 已知 f(x)=sinx·cosx，求 f'(x) 并判断单调区间 | 导数（选必，图谱未覆盖）→ 应触发「其他」 |
| T8 | 题侧独立性 | = T3 题面，仅验证输入契约不含学生痕迹 | 拆解与 T3 一致（设计层保证：节点只收题面） |

### 发现清单（喂节点设计迭代）

1. **链路全通**：识别章 → 候选检索 → 编号勾选 → schema 解析，10/10 成功；编号还原的名字全部 ∈ 候选。
2. **稳定性显著**：T2 三轮考点+难度 100% 一致——对比旧方案（同题判定漂移）机制收益明显（注：qwen 不能代表 deepseek 判定模型，此处只证机制）。
3. **"其他"出口工作正常**：T3/T8 触发，reason 依据 + 五要素(操作) 双门槛均满足。
4. 🔴 **候选外题被硬勾掩盖（T7）**：导数题被硬塞进"函数+三角"章勾了 7 个考点（只处理了 sinx·cosx=½sin2x 部分），未报 other、未标超纲——**步①就应识别"图谱外/超纲"并直接出口**，不能等步③；步③需加强"候选不足以覆盖题核心要求必须报 other"。
5. 🟡 **候选出现思想层节点并被勾选（T2 勾了"数形结合与分类讨论思想"）**：图谱可能残留 028 应归档的思想节点；步③ prompt 未约束"只勾知识层五要素"。
6. 🟡 **陷阱题关键考点可能图谱缺节点**：T5 的 a=0 退化讨论、T6 的底数边界无对应候选，模型只能勾泛化考点——需区分"图谱缺口"与"拆解判据"两类问题。
7. 🟢 **小误拆**：T2 勾"二次项系数化为正数"（本题系数已为正）、T4 勾"偶函数概念"（只考奇）——对称/通用步骤被多勾，观察是否加"只勾本题实际起作用的考点"。
8. 🟢 **候选规模正面证据**：第五章 125 候选全量喂入仍能正确勾出二倍角公式——125 规模未明显劣化。

## 8. 修复验证：候选外出口（2026-09，deepseek-v4-flash）

**修法**：步③提示词改为「拆本题**标准考察**的完整考点——不因图谱覆盖而变；候选中的用得到就勾编号；候选里没有但标准考察确实需要的点**必须填 other**（五要素命名+依据，缺一不可）；禁止勾无关候选点掩盖候选外核心考察」。拆考点保持纯题侧（不感知学生）。

**验收（T7 导数题）**：
- C6 = pass：导数完整知识链被拆出——other 9 条（导函数概念/基本初等函数导数公式/乘积求导法则/导数与单调性关系/余弦二倍角/解 cos2x 不等式…），全部满足五要素+依据；
- 硬勾消失：候选点权重被诚实压低（0.1~0.5），不再假装候选覆盖核心；
- 第五章标 outOfSyllabus=true。

**遗留观察**：两章 outOfSyllabus 不一致（第五章 true / 第三章 false）——超纲/超前标记挂在"章级布尔"上会打架；佐证应下放为**考点级派生标注**（代码：考点归属章 × 学生能力边界），拆考点只负责拆全。

**结论**：候选外硬勾问题已解决，机制 = 强 other 出口 + 纯题侧标准考察拆解。学生能力边界（已学章∪超前掌握点）完全移出拆考点，作为下游派生层与记账规则。
