## 1. 一句话背景

项目在把诊断引擎节点化（0.6.0 beta = D1–D10 路线）。D1（graphEngine 地基）✅、D2（拆考点盒子）✅ 并已真实验证。**下一个任务 = D3：设计"环节判定节点"（K 第二节点），按"节点落地 SOP"第①步（设计先行）走。**

## 2. D3 是什么（大白话）

拆考点节点（D2）解决"这道题考哪些知识点"；环节判定节点解决**下一个问题："学生做这道题时，每个考点到底用对没有"**——对着"考点清单 + 学生做题过程/痕迹"，逐考点打 P_kp：**用对了=1 / 用对一半=0.5 / 没用上=0**。它是 K 掌握度真正开始更新的入口，也是"把 judgeOne 一次大 JSON 里现成的 knowledgeUsage 判定拆出来成为独立节点"（拆 AI 的第一步）。
