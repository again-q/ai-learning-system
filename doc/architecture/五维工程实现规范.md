## 一、数据流工程层（原 §2 Pipeline 的工程动作）

```
拍照 → Qwen 图像转录（题目+做题痕迹）→ AI 拆题
  → judgeOne 逐题判定（D/P/η/归因/knowledgeUsage/pattern）
  → 掌握度更新（K 知识点粒度 / A 单元级）
  → 写入 questions / knowledge_progress / unit_progress / mastery_logs
  → text-embedding-v4 向量化 → RAG 自增强
  → 报告生成（Function Calling 调 ragService）
```

## 二、K 维度工程实现（原 §4.4 修订块、§4.2 修订块）

### 2.1 知识粒度拆解（决策 026）

判定时输出 `knowledgeUsage`：

```js
knowledgeUsage: [
  { name: "知识点教材术语", P: 0|0.5|1, D: 0~1 }   // D_kp：该知识点环节在本题的难度
]
```

- **P_kp 三档判定锚点**（由判定 prompt 按知识点自身约束，不在宪法定死）：
  - 1 = 用对
  - 0.5 = 用了但漏边界/不完整（漏特殊值验证、多选漏特殊情况、知识边界掌握不清）
  - 0 = 该环节缺失或全错
  - 涉及边界/陷阱/分类讨论的环节漏了特殊情形 → 0.5；环节根本没做 → 0
- 更新：`S_k += D_kp × P_kp`、`D_k += D_kp`，每知识点 upsert `knowledge_progress`

### 2.2 存储

- `knowledge_progress`：sValue / dValue / mastery / attempts / correctCount / lastUpdated（correctCount 只计 P_kp=1 的次数）
- `mastery_logs`：每次 K 变更 append（oldMastery/newMastery/algorithm=weighted_score_v1）——趋势/重算依赖

### 2.3 模型层 → RAG（D-18/D-19）

- 判定时生成题型三层结构 `pattern: {domain, pattern, variant}`（domain 知识板块 / pattern 中粒度题型 / variant 变体）
- 写入 `mastery_logs.pattern` + `patternEmbedding`（题型文本向量）
- 检索：`ragService.vectorSearch`——query = AI 生成的题型描述 → patternEmbedding 近邻（阈值 0.70）→ 同题型内按整题 embedding 排序

## 三、A 维度工程实现（原 §5.5）

- η（路径质量系数）：LLM 分析学生步骤文本判定，0.4~1.0，仅解答题
- 存储：`unit_progress`（aValue / aUpper / n / lowEtaStreak）
- 归因分流（决策 026 随 USE_KNOWLEDGE_USAGE 启用）：判错且 errorDimension=K/S → E=0 不进 A

---

## 四、T 维度工程实现（原 §6.4）—— ⏳ 暂缓

- W（跨类型权重）：LLM 按知识图谱判断
- r（解题质量系数）：需「学生说出深层结构」——依赖多轮引导/对话能力，拍照单向产品拿不到 → **暂缓**（后置 AI 教练对话模块）
- T_shown：LLM 综合作答+思维链判断
- 存储：每学生一个 T/TU（初始 0.10/0.60）

---

## 五、Q 维度工程实现（原 §7.4~7.6）—— ⏳ 暂缓

- 弹窗触发：AI 识别高价值题（做错/过程复杂/关键知识点）→ 弹窗问「你是怎么想的？」
- 频率自适应：`弹窗概率 = base_prob × (1 − Q)`，base_prob=0.7~0.8
- 评分：LLM 按 Q1~Q5 标准给 0~1 分；移动平均更新；Q5 首次占位 0.5、下次同类题验证后更新
- 存储：全局 Q 指数 + Q1~Q5 移动平均 + N
- 依赖弹窗交互 → **暂缓**（M6 保持待细化）

---

## 六、S 维度工程实现（原 §8.3 数据来源、§8.7 输出）—— ⏳ S0 可先做，S1~S4 暂缓

- S0 波动指数（客观）：`P_exp = w_K×K + w_A×A + w_T×T`（单元内 w=0.3/0.7/0；跨单元 0.2/0.4/0.4）；`d = |P_exp − R_actual|`；`V = 最近 N 次 d 平均`（N=20~30）——依赖 K/A/T 有值，可独立实现
- S1~S4（主观）：思维链回溯采集——依赖 Q 弹窗 → **暂缓**
- S5/S6（归因，不计入 S_global）：轻量自评 / 考试上传询问
- 输出文案示例（原 §8.7）：稳定性指数 + 波动指数 + 失常画像 + 状态/心态记录——前端展示层设计
