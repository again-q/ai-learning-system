AI 逐题判断（系统的心脏）

judgeOne现在能用主线在拆

📍 现状设计（一次大 JSON，18 字段）

  • 难度 D：L1~L11 标尺判档 → 档内按「知识复杂度/思维深度/陷阱密度/计算强度/陌生度」五维感受精调，代码钳制回区间
  • 过程分 P（连续 0~1，本身编码对错）：选填对=1/错=0；解答看与正确答案的距离分档；P≥0.5=基本答对，P<0.5=答得不好
  • 知识拆解 knowledgeUsage：逐知识点标 P_kp（0/0.5/1 三档）+ D_kp——K 更新的最小单元（决策 026）
  • 归因：breakpoint 断点 + errorAttribution（只对 P<0.5 给；空白题禁止臆测"不会"）
  • 题型三层 pattern：domain/pattern/variant → 存向量供检索
  • 注入上下文：RAG 同类题 top5 + 知识点节点全清单（AI 从规范名挑，不自由造名）+ 历史数据
  • 复核支持：改转录 / 自然语言改题干 / 改参数 → 掌握度自动迁移
  • 判定思考档位：判档走 thinking-disabled 链路（快省）；DeepSeek/GLM 路由见决策 029

🔧 正在改进（主线）

  • 把「一次大判断」拆成两条小链 + 门禁路由：
    　题侧链：认题 → 考点清单 + pattern + D + 超纲 + 标准解法（可缓存、可人工复核）
    　生侧链：题侧产物 + 学生痕迹 → 逐考点 P_kp + 断点 + 归因
  • K 拆解基准 = 题目侧知识链（学生没碰的环节也要列出，过程只用于打分）
  • 三门禁路由：题型分类 → 标准答案三层降级 → 归因映射
  • 承载：JS LangGraph 内嵌云函数；checkpoint 存云库 → 判定失败续跑只重跑挂掉的题
  • 做法：先 A/B 评测（现状 vs 门禁切分版）验证稳定性，再切生产；窗口 9/8–9/15
  • 每节点配验收标准（短期不做审查 skill，先记住原则）

🚀 远期构想

  • 题目侧判定全局缓存（同题只判一次，跨学生复用）
  • 归因证据链细化（决策 012 深化：M8）
  • 判定与报告的解耦：不同模块用不同模型（GLM × DS 模块矩阵，已试点）
  • 薄弱点解释能力（把"为什么这么判"讲给学生听）

陪你复盘（思维链采集：Q 反思 & S 稳定）

决策 030/031 · v1.5方案已定，还没做

📍 为什么是"先听后答"

  • 直接给学生看 AI 结论，学生就"照着 AI 说"，测不出真实反思能力（锚定）
  • 先让学生回忆"当时怎么想的"再看分析 = 记得牢、练"自我检查"（calibration training）
  • 科学上：反思采集同时就是在训练反思能力——采集与训练合一

🔧 已定设计（等 v1.5 做）

  • 系统挑题（判值器，纯代码）：错题 / 过程复杂 / 关键节点 → "值得想想"的题；另有"会做却做错"的失常题单独挑
  • 报告页显示"本次有 N 道值得想想的题"，整题锁：对错/断点/归因都不先给
  • 学生可跳过（不强制）；愿意就语音说：做到哪一步卡住 → 当时怎么想的 → 怎么处理的
  • 说完全部解锁 + 对照反馈（你说的 vs AI 分析的）
  • 评分：LLM 按 Q1~Q5（觉察/归因/调整/反思/结果）打 0~1，移动平均；Q5 要等"下次同类题做对没"再验证
  • 学生自报逐字采纳（假设诚实），AI 比对只做报告内容、不做校验官

🚀 远期构想 & 待定

  • 待定：跳过后解析怎么处理 / 对但过程复杂的题锁不锁 / 失常题要不要先提示"这题你会但没发挥出来"
  • S 客观波动 S0 = 预期分 vs 实际分偏差（纯代码算，其实不依赖弹窗，v1.5 可先落地）
  • v2.0 对话私教承接更深层：单题追问 → 完整对话（T 的 r 也需要对话）
  • 采集频率与学生 Q 值负相关：反思弱的反而要多提醒（细节 v1.5 调）
