## 〇、一句话

**U 是能力前沿，A 是实际发挥（A ≤ U 结构性成立）；难度只作准入门槛，不进数值；
A、U 都定义在 λ 轴（档位坐标）上，让"每一档的进步"等权。**

---

## 一、理论定位：随机前沿分析（SFA）

```
U = 能力前沿（真实能力 / 最大表现）      ← SFA 里的 f(x)
A = 实际发挥（典型表现）                  ← SFA 里的实际产出 y
A ≤ U 结构性成立（发挥总有损失，单边误差 u ≥ 0）
[A, U] = 余量区间
```

**用户原话（2026-10-06）：**
> **「在高考当中，你能发挥出你应有的实力，那就是超常发挥。
>  实际发挥永远是低于估计的那个真实的，而真实的能力就是我们所估计的。」**

**文献支持：**

| 理论 | 对应 |
|---|---|
| **随机前沿分析（SFA）** | `y = f(x) − u`（u ≥ 0 单边误差）→ U 是前沿，A 是产出 |
| **Typical vs Maximal Performance**（Sackett & Zedeck） | 典型表现系统性低于最大表现，两者相关中等（r ≈ 0.42） |
| **Latent State-Trait 模型** | Trait（稳定能力）vs State（特定时刻表现） |

**推论：**
```
A ≤ U 不是"我们估计高了"，而是"发挥总有损失"—— 结构性，不是偏差
"发挥出全部实力"（A = U）是罕见事件，所以叫"超常发挥"
```

## 二、为什么用 λ 轴而不是 D 轴

### 2.1 D 是金字塔刻度

| 档位 | D 区间 | 档宽 |
|---|---|---|
| L1 | 0.01–0.15 | 0.140 |
| L4 | 0.45–0.60 | 0.150 |
| L6 | 0.70–0.79 | 0.090 |
| L8 | 0.85–0.90 | 0.050 |
| L9 | 0.90–0.94 | **0.040** |

**档宽从 0.140 缩到 0.040（缩了 3.5 倍）—— 这个"金字塔"形状编码了"越高越难"。**

### 2.2 D 轴做更新会破坏这个编码

```
D 轴的步长是【绝对值】：ΔA = 0.1 × 惊讶度（固定 0.1 个 D 值）

换算到档位：
  L1（档宽 0.140）→ 一步跨 0.71 档
  L9（档宽 0.040）→ 一步跨 2.50 档  ← 跨一整档还多
```

| 档位 | D 轴一步跨几档 |
|---|---|
| L1 | 0.71 |
| L5 | 1.00 |
| L7 | **1.67** |
| L8 | **2.00** |
| L9 | **2.50** |

**即：D 轴在高档位"跳着走"，与"越高越难"相反。**

### 2.3 λ 轴修正了它

```
λ = 档位坐标（L1 起点 = 0，L9 终点 = 9，每档恰好 1.0）

λ 轴的步长是【相对值】：Δλ = α_λ × 惊讶度
→ 任何档位，一步都是 0.9 档（均匀）
→ 换算成 D 值后，高档位的进步自动变小
→ 与"越高越难"一致 ✅
```

**用户原话（2026-10-06）：**
> **「正常不就是应该在档位上面均匀吗，因为越高的提得越慢啊」**

### 2.4 λ 的定义

```
λ(D)：按 L 表分段线性，L1 起点 = 0，每档占 1.0

D 值   │ λ      │ 档位
0.30   │ 2.000  │ L3 简单题（档内 0%）
0.50   │ 3.333  │ L4 中下题（档内 33%）
0.60   │ 4.000  │ L5 中档题
0.70   │ 5.000  │ L6 中档→中上
0.79   │ 6.000  │ L7 中上题
0.85   │ 7.000  │ L8 较难题
0.90   │ 8.000  │ L9 较难→极难
0.94   │ 9.000  │ 课内极限

归一化：A_norm = λ / 9.2  →  课内极限 = 0.978
```

## 三、核心公式

### 3.1 期望过程分

```
E(P | λ_D) = 1 / (1 + e^{ k(λ_D − m) / s })

  s = (λ_U − λ_A)/2 + s₀λ                   半宽（含状态噪声下限）
  m = λ_A − (s/k) · logit(1 − p_t)          中点（由 p_t 反解）

  效果：E(λ_D = λ_A) ≡ p_t（恒定，与区间宽度无关）
```

**为什么 m 要反解（而不是直接取中点）：**
```
若 m = (λ_A + λ_U)/2（中点）：
  E(λ_A) 会随区间宽度漂移
  → gap 小的时候 E(λ_A) 掉到 0.65
  → A 的语义变成"一半一半"，不稳定

反解后：
  E(λ_A) ≡ p_t = 0.80（恒定）
  → A 永远是"在这个难度上，有一定把握做出过程分 0.80"的位置
```

### 3.2 A 的更新

```
λ_A ← λ_A + α_λ · (P − E)
约束：0 ≤ λ_A ≤ λ_U
```

**A 对任何观测都更新**（含 ⑤ 区的微涨）。

### 3.3 U 的更新

```
【抬升】④区：D > D_U 且 P ≥ P_c
   λ_U ← max( λ_U , λ( min(0.94, D · g(P)) ) )
   
   g(P) = a_u + (1 − a_u) · (P − P_c)/(1 − P_c)
   
   含义：P=1.0 时完全承认该难度；P=P_c 时承认 a_u 倍

【下调】②区累计 k_low 次：D < D_A 且 P < P_c
   λ_U ← λ_U − δ_d · (λ_U − λ_A)
```

### 3.4 🔑 A 可动、U 不可动（关键区分）

**用户原话（2026-10-06）：**
> **「如果只是加 A 没事，加 U 就不行了」**

```
⑤ 区（D > U 且 P 低）：
  · A 微涨 ✅ —— 他确实拿到了分，A 反映实际
  · U 不动 ❌ —— 他没做出来，不能据此抬高能力前沿
```

**理论基础：**
```
A = 实际发挥 → 任何实际发生的事都反映
U = 能力前沿 → 只有【确证做到】（P ≥ P_c）才能抬高
```

### 3.5 ① 区不需要硬忽略

**用户原话（2026-10-06）：**
> **「做简单题，有 U 限掉就可以了」**

**实测验证（只做 D=0.25 的题、P=0.95）：**

| 题数 | A（D值） | U（D值） |
|---|---|---|
| 1 | 0.3048 | 0.5000 |
| 20 | 0.3228 | 0.5000 |
| 50 | 0.3232 | 0.5000 |
| **2000** | **0.3232** | 0.5000 |

```
→ 刷到 50 题就收敛，再刷 2000 题也不动
→ 上限 = U 的位置，且远低于 U
→ 因为 U 不会被简单题抬高（D=0.25 < U，不满足 D > U）
```

**所以"A 刷简单题涨高"这条路被 U 钳制堵死，不需要额外的硬忽略分支。**

## 四、参数表（锁定）

| 参数 | 值 | 语义 |
|---|---|---|
| `k` | 3 | 期望曲线陡峭度 |
| `s₀λ` | 0.35 | λ 轴状态噪声下限（≈1/3 个档位） |
| `p_t` | 0.80 | A 处的期望过程分（"有一定把握"） |
| `α_λ` | 0.9 | A 更新步长（λ 单位） |
| `δ_d` | 0.03 | U 下调幅度 |
| `k_low` | 3 | ②区累计触发次数（事不过三） |
| `P_c` | 0.6 | U 抬升的过程分门槛（相变临界） |
| `a_u` | 0.75 | U 抬升时的压缩系数 |
| `归一化分母` | 9.2 | 使课内极限 = 0.978 |
| `A₀` | λ(0.30) = 2.00 | A 起点 |
| `U₀` | λ(0.50) = 3.33 | U 起点 |

**参数来源：**
```
· 全部为冷启动值，待真实数据校准
· P_c = 0.6 的语义：判定"会/不会"的相变临界（用户定）
· p_t = 0.80 的验证：p_t 越大，"①区漂移"越小且最终归零
  → 0.80 让漂移收敛到有界（不是"调出来的"，是设计要求的自然满足点）
```
