## 二、LLM 计算引擎（固定权重 + 公式）

**权重（理论 §4.4 五维加权，固定值）：**

| 维度 | 权重 |
| :--- | :---: |
| 知识复杂度 | 0.30 |
| 思维深度 | 0.30 |
| 陷阱密度 | 0.133 |
| 计算强度 | 0.133 |
| 陌生度 | 0.133 |

**公式（与理论一致）：**
```
原始加权分 = 知识分×0.30 + 思维分×0.30 + 陷阱分×0.133 + 计算分×0.133 + 陌生分×0.133
D = (原始加权分 − 1) / 4
D 值范围：0.01–0.999
```

## 三、判定流程（v5 定稿：档位钳制 + 档内自由取值，决策 021）

```
第 1 步：AI 判 Lx 档（分类任务，用「边界判定速查卡」+ 例子锚参照）→ 边界锁死
第 2 步：AI 在 Lx 区间内自由打一个连续 D 值
         · 比锚例简单 → 靠下沿；和锚例相当 → 中段；比锚例多变形/陷阱 → 靠上沿
第 3 步：代码钳制：D = clamp(D, Lx_lo, Lx_hi)，越界钳回边界
```

**核心认知（实测结论）**：档位 = 硬边界（分类任务，卡住大漂移）；档内 = 轻回归（自由取值，保留微区分）。AI 擅长分类、不擅长打连续值——让它在窄区间（宽度≤0.15）内自由发挥，漂移被边界兜住。

**5 维加权公式降级为校验器**：`D=(原始加权分−1)/4` 仅用于人工标定时校验 D 是否落档，不再作为 AI 主判据。

**RAG 排除**：D 难度不用 RAG 实时学习（难度是绝对属性；RAG 只做诊断证据检索）。
