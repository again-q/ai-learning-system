## 二、LLM 计算引擎（固定权重 + 公式）

**权重（理论 §4.4 五维加权，固定值）：**

| 维度 | 权重 |
| :--- | :---: |
| 知识复杂度 | 0.30 |
| 思维深度 | 0.30 |
| 陷阱密度 | 0.133 |
| 计算强度 | 0.133 |
| 陌生度 | 0.133 |

**公式（与理论一致）：**
```
原始加权分 = 知识分×0.30 + 思维分×0.30 + 陷阱分×0.133 + 计算分×0.133 + 陌生分×0.133
D = (原始加权分 − 1) / 4
D 值范围：0.01–0.999
```

## 三、判定流程（两段式，rubric 实测定稿）

```
第一步：AI 用「边界判定速查卡」判 Lx 档（分类任务，最稳——实测分类远稳于回归）
第二步：AI 在 Lx 档锁定的 5 维分值范围内打分（如 L4 锁定 知识2/思维2/陷阱1/计算3/陌生2）
代码侧：D = (原始加权分−1)/4，校验落在 Lx 区间内，越界则钳制回 Lx 边界
```

**双保险**：Lx 档位卡住漂移（选错最多偏一档），公式保证连续值。
