## 二、五维考虑维度（参考，不参与计算）

> **2026-08-11 更新**：原「5 维加权公式」已废弃——D 判定改为「学生视角体验 + 标尺直接判档」（决策 023），不再打分加权。

判断一道题的难度，**从以下五个方面综合考虑**（定性参考，不打分、不加权）：

| 维度 | 含义 |
| :--- | :--- |
| 知识复杂度 | 涉及多少知识点、知识层级多深 |
| 思维深度 | 推理链条多长、是否需要抽象/构造 |
| 陷阱密度 | 容易错的地方有多少、多隐蔽 |
| 计算强度 | 计算量、运算复杂度 |
| 陌生度 | 题型/新定义对学生有多陌生 |

## 三、判定流程（v6 定稿：学生视角判档 + 五维感受打值，决策 021/023/024）

```
第 1 步：学生视角感受（模拟对应水平学生：卡在哪/几次跳跃/试错成本）→ 体验难度
第 2 步：AI 判 Lx 档（分类任务，用「边界判定速查卡」+ 例子锚参照）→ 边界锁死
第 3 步：先在档位区间内凭第一直觉形成初步 D 判断（偏简单/中等/偏难），
         再逐维审视五维难度特征（知识复杂度/思维深度/陷阱密度/计算强度/陌生度，
         每维低/中/高三档描述见下），每维感受后决定向上/向下浮动修正：
         多数维度偏低→明显下浮(下沿附近)；高低参半→小幅浮动(中段附近)；
         多数维度偏高→明显上浮(上沿附近)；单维特别突出→至少上浮一档内位置
         （描述性规则，无公式/无加权/无基准——决策 024 用户定稿）
第 4 步：代码钳制：D = clamp(D, Lx_lo, Lx_hi)，越界钳回边界
```

**已知局限（实测）**：档内 D 值有趋中倾向（模型行为，prompt 已最简无法再压）；梯度区分由**二次复核人工修正**兜底。

**核心认知（实测结论）**：档位 = 硬边界（分类任务，卡住大漂移）；档内 = 轻回归（自由取值，保留微区分）。AI 擅长分类、不擅长打连续值——让它在窄区间（宽度≤0.15）内自由发挥，漂移被边界兜住。

**RAG 排除**：D 难度不用 RAG 实时学习（难度是绝对属性；RAG 只做诊断证据检索）。

## 十、D 定义补充说明（2026-08-11 定稿 · ✅ 正式采用）

### D 是题目的固有属性，不是学生的主观感受

**D 的职责**：告诉系统「这道题本身值多少认知增量」——它是五维更新的乘法因子（K=Σ(D×P)/ΣD 等），唯一身份是"题目本身的结构难度"。

**D 不受学生熟练度影响**：
- 学生做多了觉得简单 → 那是 **K（掌握度）涨了、A（应用能力）强了**，不是题变简单了
- 若为迁就"学生觉得简单"调低 D → 掌握度权重失真（一道 D=0.7 的题调成 0.6，做对时掌握度少算 14%）→ **诊断反而更不准**
- S 维度用 D 做锚：学生熟练后的正常做对 = K 高 + D 不变的正常结果，S 诊断自动识别，不需要 D 变化

**判定要求（已实测）**：AI 判 D 时必须「**只看题，不看人**」——不理会学生是否刷过此题，只按题目结构打分。

**案例佐证（2022 新高考Ⅰ卷 18 题）**：AI 判 D=0.7（跨三角函数+基本不等式、4-6 步、恒等变换+最值两思维节点），教研视角觉得该 0.6（学生练熟了）。**AI 是对的**——0.7 是题目固有结构难度，"练熟了觉得简单"应由 K/A 维度消化，不该让 D 背锅。这 0.1 的差正是「学生熟练度感知差」的最佳案例。

### 一元二次方程求根公式示例

本身 D=0.6（3 步推导、跨配方与公式应用），初一觉得难、高三秒出——**不是 D 变了，是学生 K 从 0.1 涨到 0.9**。AI 打那个固定的 0.6，完全合理。

## 十一、同题缓存（抹平采样波动，2026-08-11 · ✅ 正式采用）

D 判定（学生视角+标尺）单次有 ±0.05 档位波动（L8↔L9）。**同题缓存**：同一道题只判一次，命中直接返回，从根上抹平波动。

**Key 设计**（OCR 哈希 + 题目特征指纹）：
```
key = SHA256( canonical_text + feature_fingerprint )

canonical_text    = 题面标准化文本（去空白/统一符号/排序选项）
feature_fingerprint = 知识点标签集 + 题型 + 结构签名
                      （如 "三角恒等变换+基本不等式+最值求解" 的结构签名）
```

**伪代码**：
```
function getD(question):
    key = SHA256(canonicalize(question.text) + featureFingerprint(question))
    cached = cache.get(key)
    if cached:                      # 命中：直接返回，零波动
        return cached.D
    # 未命中：3 次判定取平均（temperature 0.2）
    results = []
    for i in 1..3:
        results.append(judgeByStudentPerspective(question))   # disabled + t0.2
    D = average(results)
    cache.set(key, { D, level, createdAt: now() })
    return D
```

**效果**：同题二次诊断直接返回缓存 D（0.05 波动归零）；新题 3 次取平均（±0.02 收敛）。
