2参考过程这道题的标准做法
看完整参考过程（5 步）
  1. 1第一步：确定 M 的取法
    M⊆ A，A 有 5 个元素，故 M 有 2^5=32 种取法。
  2. 2第二步：固定 M 后数满足条件的 N
    对固定的 M，N 需满足 M⊆ N 或 N⊆ M。若 M⊆ N，则 N 须包含 M 的全部元素，其余 5-|M| 个元素任取，共 25-|M| 种；若 N⊆ M，则 N 是 M 的子集，共 2|M| 种。两者交集为 M=N，被重复计 1 次。故对固定 M，满足条件的 N 有 25-|M|+2|M|-1 种。
  3. 3第三步：按 |M| 分类求和
    |M|=0：2^5+2^0-1=32；|M|=1：2^4+2^1-1=17；|M|=2：2^3+2^2-1=11；|M|=3：2^2+2^3-1=11；|M|=4：2^1+2^4-1=17；|M|=5：2^0+2^5-1=32。
  4. 4第四步：加权求和得总数
    C(5,0)×32+C(5,1)×17+C(5,2)×11+C(5,3)×11+C(5,4)×17+C(5,5)×32=32+85+110+110+85+32=454。
  5. 5第五步：排除 M=N 的重复计数
    上述计数中 M=N 的情形被重复计入（M 与 N 互换视为同一 B）。M=N 时 B={M,M} 不构成含两个不同元素的集合，需排除。M=N 的取法有 2^5=32 种，故符合条件的 B 有 454-32=422 种。

  2. 2第二步：第(1)问——a-1=0 情形

  3. 3第三步：第(1)问——a-1≠0 情形

  4. 4第四步：第(1)问结论

  5. 5第五步：第(2)问——B=∅ 情形
    当 a=1 时 B={0}⊆ A；当 a≠1 时，B=∅ 需 Δ<0，即 3a^2-8a+4>0，解得 a<23 或 a>2。
  6. 6第六步：第(2)问——B≠∅ 情形

  7. 7第七步：第(2)问结论
    综上，a 的取值范围为 a<23 或 a=23 或 a>2，即 a≤23 或 a>2。
