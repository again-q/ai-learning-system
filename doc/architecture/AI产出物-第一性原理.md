# AI 产出物 —— 第一性原理（唯一取舍判据）

> 状态：2026-09-25 立（用户问：「我们真正想要的是什么？」并指出当前在细节上打转、像泥潭）
> 定位：**以后任何设计取舍，先对这份。**对得上就做，对不上就是泥潭。

## 一句话

**我们要 AI 产出的不是「结论」，而是三样东西：一句有证据的话、一个下次能做的动作、一个学生能推翻它的入口。**

不是「告诉学生他怎么了」，而是 **给他一面自己能照的镜子**。

## 一、为什么是这三样（从学习机制推）

学习发生只有三个环节：**预测 → 落差 → 归因**。AI 的产出必须落在「落差」和「归因」上，**不能替代「预测」**。

| 学习环节 | AI 该做什么 | 对应要求 |
|---|---|---|
| 预测（学生先自己想） | **不抢**：不许先给结论 | → **可反驳**（保护学生先有判断） |
| 落差（预期 vs 实际） | 把差异**指到具体位置** | → **可核验**（每句话有证据） |
| 归因（错在哪个动作） | 加一个**替代动作** | → **可执行**（结尾必须是动作） |

## 二、三条要求 · 以及它们各自消灭哪类纠结

| 要求 | 含义 | 它自动消灭的纠结 |
|---|---|---|
| **可核验** | 每句话都能指回证据（卷面哪一处、哪一步、哪个字） | 「会不会猜错学生心理」→ 不靠措辞谨慎，而靠**结构上不许它下无证据的心理断言** |
| **可执行** | 结尾必须落到一个具体动作（下次遇到同类结构先做什么） | 「报告看着不错但没用」→ 判定标准从「说得好不好」变成「**学生能不能照着做**」 |
| **可反驳** | 学生能一键推翻，且系统必须改 | 「信任度会不会下降」→ 信任不来自 AI 说得准，来自**AI 错了能被纠正、且学生看到自己被采纳** |

**关键洞察**：纠结之所以是泥潭，是因为只要产出是「关于学生内心的断言」，它**永远无法核验**——可以永远争论「他到底是粗心还是没懂」。
把产出**从「断言」改成「可核验的过程描述 + 可执行的动作」**，核验标准就从「说得对不对」变成「**学生自己能不能确认**」——泥潭自动消失。

## 三、取舍判据（对任何细节都适用）

> 任何细节：**只要能提高「证据充分性 / 动作具体性 / 可反驳性」三者之一 → 值得做。**
> **只是在让措辞更稳妥、更委婉、更不容易被挑毛病 → 泥潭，砍掉。**

用它检验用户举的三个例子：

| 纠结 | 泥潭式解法（别做） | 结构式解法（该做） |
|---|---|---|
| 会不会猜错学生心理 | 反复推敲措辞、加免责话 | **禁止无证据的心理断言**（报告里每句必须有证据指针） |
| 信任度会不会下降 | 语气更温和、少说问题 | **一键推翻 + 采纳可见**（学生改一次，系统立刻认账） |
| 万一模型判错了 | 不停调参、加更多字段 | **让错误可见、可纠正、不造成伤害**（错误不 Hidden、不放大） |

## 四、推论：结论性判断该归谁

| 判断 | 谁来做 | 依据 |
|---|---|---|
| 对错 | **事实来源**（学校/智学网官方分） | 决策 042 的正当性在这里：对错是事实，交给官方 |
| 掌握度 / 五维分数 | **要么由学生自己得出（被引导），要么由可核验事实推出** | 报告已禁止输出数值（systemV3 规则 10）——与本文一致 |
| 过程与动作 | **AI**（这是我们唯一的差异化） | 官方给不了「你第 2 步漏了分类讨论」 |

> 一句话：**AI 不做裁判，做镜子。**

## 五、三个工程检查点（照这个验收）

1. 报告里每句话，**能否指回一个证据指针**（第几段/哪处原文）？不能 → 删
2. 每个「发现的问题」，**是否配了一个动作**？没有 → 不算完成
3. 学生**能否一键推翻**并立刻看到影响？不能 → 优先修这个（比加字段重要）

## 六、用它整理现状（哪些先做）

| 现状 | 对照三条 | 结论 |
|---|---|---|
| 过程分段 / 断点 / 错因 | 可核验 ✅（有 evidence 引用） | **底座已对**，继续加厚 |
| 报告里的「下一步」 | 可执行 🟡（有 hook，但不够具体） | 往「可照着做」推 |
| 异议入口（**0 次使用、入口点不到**） | 可反驳 ❌ | **优先级应高于一切新功能** |
| 掌握度 / 五维数值 | 与「不做裁判」一致 | 保持不展示；先修图谱科目表（记账可信） |
| 图谱 / 判定精度 | 是**支撑**不是目的 | 按框架文档排序，不为精度而精度 |
