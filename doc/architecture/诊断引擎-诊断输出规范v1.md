# 诊断输出规范 v1 — 我们真的诊断什么

> 生成：2026-08-11
> 目的：明确诊断引擎的**输出对象**——先搞清楚"诊断什么"，再谈实现。
> 依据：第一性原理（采集轻量化、诊到根）+ 21 项学习技术第 21 章「错误根源诊断」（四步归因）+ 19 题真实过程实测。

---

## 一、诊断对象（一句话）

**诊断的不是"这道题对错/多难"，而是「学生的断点位置 + 断点处对应知识链的根」。**

诊断的输入是**过程**（不是结果），输出是**断点**（不是答案）。

## 二、诊断输入（只拍照，零额外负担）

```
学生做题的完整痕迹（拍照）
  → Qwen 转录：分段的解题过程（每步写了什么）+ 痕迹观察（涂改/停顿/空白）
```

## 三、诊断产出结构（五个字段，全部证据可撑）

| 字段 | 内容 | 证据来源 | 确定性 |
|---|---|---|---|
| ① 分段路径 | 题目被学生推进到哪些段，每段「通 / 断 / 空白」 | 过程转录逐段标记 | 确定 |
| ② 断点位置 | 学生在哪一段停下（未完成/空白/中断） | 过程转录 | 确定 |
| ③ 断点性质 | 起步即停（无从下手）/ 中途断（算错/卡住）/ 收尾断 | 断点处痕迹形态 | 确定 |
| ④ 根（知识层） | 断点段对应的知识点 → 沿图谱 reference 链定位到断裂处 | **断点 + 知识图谱链对照** | 逻辑必然 |
| ⑤ 证据摘要 | 支撑以上结论的过程原文片段 | 转录 | 确定 |

**不做**（v1 明确排除）：
- ❌ 不解题（不给出答案/解法）
- ❌ 不判难度（D/Lx 与诊断无关）
- ❌ 不猜"为什么卡"的深层原因（经验/策略/情绪等——需互动，后置给 AI 教练）
- ❌ 不做改进方案（后置）

## 四、诊断逻辑（为什么成立）

```
学生断在某段 + 断点前路径全通
  ⇒ 根必然在断点段对应知识点链处（前通后断 ⇒ 断裂必在断处）
  —— 这是逻辑必然，不是模型推断，不需要解题
```

对照 21 项技术四步：本规范实现前两步 + 知识层根源一步（第三步取"知识层"这一层，21 项技术原话"不必查完七层，够深即可"）。

## 五、完整示例（2026 新高考Ⅰ卷 19 题 · 学生过程）

**输入**：学生手写过程转录（见附 A）。

**输出**：

```
诊断报告
────────────────────────────────────
① 分段路径：
   (1) 求 D(-1)          → ✅ 通（含一次自我修正后走通）
   (2) 证 D(x₂)⊆D(x₁)    → ✅ 通
   (3)(i) 证 f(0)≥1      → ✅ 通
   (3)(ii) 证单调递增     → ⬜ 断（只写"证 f(x)在"后空白）

② 断点位置：(3)(ii) 起步处

③ 断点性质：起步即停（无从下手型）——断点段无任何推导痕迹

④ 根（知识层）：
   - 断点段对应能力：把"单调递增"翻译成 D 集合语言
   - 该能力的知识链：集合语言 → 函数性质 → D 集合刻画单调性
   - 学生路径实证：链上前三级（集合/函数性质/抽象构造）全部通过
   - ⇒ 根 = 断点段这一级（"单调性 ↔ D 集合语言"翻译）——前置无断裂，根不在前置
   
⑤ 证据摘要：
   - (1) 划掉 2^(d-1)>1/2 重算 → 通
   - (2) 画草图辅助 → 通
   - (3)(i) 从数值例子升级到 log₂c 构造 → 通
   - (3)(ii) 仅存"证 f(x)在"，无后续 → 断
────────────────────────────────────
```

**这个输出回答了"诊断什么"**：断在哪（(3)(ii) 起步）、断的性质（无从下手）、根在哪（该段对应的 D 集合语言翻译能力）——全部由过程 + 图谱链支撑，零猜测、零解题、零额外负担。

## 六、与现有代码的差距

| ②③ 断点位置/性质 | 无 | 新增 |

## 七、诊断 → 五维参数映射（v1 诚实版）

**诊断的最终产出 = 五维参数更新（掌握度画像）**，"断点+根"是中间结论。

| 五维 | 诊断信号 | v1 能算吗 |
|---|---|---|
| **K**（知识掌握） | 逐段通/断 = 每段对应知识点的**掌握证据**（通=正证据，断=缺口证据）；根=缺口节点 | ✅ **能**——按理论（Sₖ/Dₖ 加权或 BKT）更新 |
| **A**（应用能力） | 需要过程质量信号（η 路径质量） | 🟡 部分（通的段可评） |
| **Q**（思维品质） | 需元认知/思维链信号（涂改不足以证明，已否） | ❌ 证据不足 |
| **T**（迁移能力） | 需跨题/跨单元信号 | ❌ 单题不够 |
| **S**（执行稳定） | 需多次重复/波动数据 | ❌ 单题不够 |

**v1 结论**：只可靠更新 **K**（"通/断"是确定证据）；A/T/Q/S 信号不足，硬算=编造，违反"不猜"原则，留给后续（互动数据、跨题积累）。

**自洽性**：图谱掌握度着色（K 维度）获得真实数据源；五维雷达的 A/T/Q/S 保持未学，等数据积累。

## 八、D 难度参数方案（2026-08-11 定稿）

**D 判定 = thinking disabled + temperature 0.2 + 学生视角体验 + 我方 L1-L11 标尺判档，连跑 3 次取平均。**

- 流程：模型模拟学生视角感受难度（卡在哪/几次跳跃/试错成本）→ 对照 L1-L11 标尺（边界卡+例子锚+新定义补充+5维锁定）判档 → 输出 level + D
- 实测：2026 新高考Ⅰ卷 19 题 (3)(ii)，5 次全落 L8-L9（0.87-0.92），均值 0.89 ≈ 真实 0.92；3 次取平均 ≈ 0.887，稳定收敛
- 成本：~21s（3 次）
- 关键认知：**难度是体验属性**——学生视角（模拟卡顿）比冷静分析（数步骤）更接近真实难度；thinking 开 + 难题 = content 空死锁（9 次试错证伪）
