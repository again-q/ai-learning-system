# 诊断报告重构 · 以「镜子原则」为第一性原理（2026-09-26）

> **第一性原理出处**：`doc/architecture/AI产出物-第一性原理.md`（决策 047，已入宪法 §一）。本文只做一件事：**从这份公理推导报告结构**，不新增任何偏好。

## 0. 公理（原文引用，不改写）

| # | 公理 |
|---|---|
| A1 | **我们要 AI 产出的不是「结论」，而是三样东西：一句有证据的话、一个下次能做的动作、一个学生能推翻它的入口。** AI 不做裁判，做镜子（镜子越用越自立，裁判越用越依赖）。 |
| A2 | 学习只有三个环节：**预测 → 落差 → 归因**。AI 必须落在「落差」「归因」上，**不能替代「预测」**（不许先给结论）。 |
| A3 | 验收标准不是「AI 说得准不准」，而是「**学生看完之后的动作**」——动作可观测、能归零；内心不可观测、永远争不完。 |
| A4 | 取舍判据：能提高「**证据充分性 / 动作具体性 / 可反驳性**」之一 → 做；只是在让措辞更稳妥委婉 → **泥潭，砍**。 |

三问裁决：**① 证据在哪？② 下一步动作是什么？③ 学生能不能推翻？**

## 1. 从公理推出的五条结构约束（推导链）

| 约束 | 从哪条公理推出 | 对报告的直接含义 |
|---|---|---|
| **C1 每块内容必须归属三要素之一** | A1 + A4 | 报告的模块表只有三列：证据 / 动作 / 反驳入口。**归不进去的内容，删**（这条是"砍"的机械判据） |
| **C2 顺序不可反：先学生的东西，后 AI 的话** | A2（预测不许抢） | 第一屏必须是**学生自己的题面 / 过程原文 / 得分**；AI 的解释必须排在后面、且**由学生主动展开**才出现 |
| **C3 报告有"完成"的定义** | A3 | 报告的终点是**学生做出了一个动作**（点开证据 / 推翻一条 / 选一个归因 / 照做一条）。没动作 = 报告失败（可埋点观测） |
| **C4 AI 的话量 ∝ 证据强度（反向绑定）** | A3 + A4 | 样本 <2 或过程不可信 → **AI 不说话**，只摆事实。措辞量随证据增加而增加，**不随"想说得更清楚"而增加** |
| **C5 反驳必须能推翻"判定结论"本身** | A1（可反驳） | 现状只有「题型异议」能点到（`review.js` 的异议弹层），而能推翻判定的 `cloudfunctions/dispute` **前端 0 调用**且内含已废口径 → **这是 A1 的直接欠账** |

## 2. 新报告结构：五段动线（0 看自己 → 1 你的账 → 2 落差 → 3 归因 → 4 动作）

### 动线（对应学习三环节，顺序即约束 C2）

| 段 | 名称 | 它回答什么 | 内容（全部来自已落库的确定事实） | 归属 |
|---|---|---|---|---|
| **第 0 段** | **冰面 · 先看自己** | 「我刚才发生了什么？」 | 本次题目点阵（✓/△/✗）+ 官方得分（若有，对错归官方=决策 042）；每题：题面 + **学生过程原文分段**（通/断/空白，可点开裁剪图看真实笔迹）。**此段零 AI 文字** | 证据 |
| **第 1 段** | **你的账 · 跨题统计** | 「我自己的历史到底长什么样？」 | 本题用到的**每个知识点**：考几次 / 对几次（附清单可点开）+ 按用对率排序 + 环节覆盖（`knowledgeUsage[].P` 的跨题对齐）。**机器算的，零 LLM 措辞**。真实示例：空集的性质 **9 考 1 对**、集合与元素的字母表示 **20 考 4 对** | 外接记忆（§2.5 ①） |
| **第 2 段** | **落差 · 并排对照** | 「我写的那一步，和标准这一步差在哪？」 | 每道错题：**你写的那一段 ↔ 参考过程同一步**，手机上**上下叠**（不并排两列）、差异高亮，断点标成位置（第 N 段）。**只并排，不解释**：禁止「你是因为……」 | 证据 + 落差 |
| **第 3 段** | **归因 · 你说了算** | 「这一步更像是哪种情况？」 | 每个断点给 **2~3 个都有证据支持的候选读法**（没写完整 / 法则用错 / 抄写失误），**学生选或自己写**；选择写回数据（`questions.revisions[]` 已有此字段），成为下一轮的可观测证据。这是 **AI 唯一允许"说话"的地方**，且遵守 C4 | 归因 + 校准入口（§2.5 ③）+ 反驳 |
| **第 4 段** | **动作 · 下次先做什么** | 「我明天做什么？」 | 每条动作必须**绑定第 2/3 段的某个断点**（例：把第 2 段重写一次 / 再做 2 道同题型题 / 下次遇到"含参"先列边界条件）。**必须是可观测动作**，不是"理解一下概念" | 动作 |

### 台账（贯穿全篇，机器生成，零 LLM，可复现）

- **K**：叶子「用对率」——展示形式是**证据条目**（哪几次对、哪几次错、错在什么），数值折叠在"想看细节"里（见 §7 拍板点 1）
- **A**：单元级熟练度 + 趋势（`unit_progress`，目前无消费端）
- **样本量**：`attempts` + `evidence`（`insufficient` → 只写"样本不足，再多练几题"，**不给结论**，C4）
- **可追溯**：每个数字都能点开看「它由哪几道题算出来」（这是"能推翻"的物理基础）
- **数据源**：`knowledge_progress`（mastery/attempts/correctCount/evidence/aggregated）、`unit_progress`、`mastery_logs`

## 2.5 价值函数：报告只给「学生自己产生不了的信息」（2026-09-26 立）

> 设计依据：报告若只给「对比 + 建议」，对元认知强的学生是**零信息量**（这两件事他自己已经做完），对元认知弱的学生是**拐杖**。

**这条质疑成立，且必须写进取舍判据**：对比（第 2 段）与建议（第 4 段）都是**学生自己有能力的动作**。

- 对元认知弱的同学：报告替他做 → **是拐杖**（有价值）
- 对元认知强的同学：他自己已经做了 → **零信息量**（冗余）

所以报告的价值不在「给判断」，而在**给出他产生不了的信息**。按「为什么产生不了」分三类：

| 类 | 他为什么产生不了 | 报告给什么 | 数据是否已有 | 示例中的位置 |
|---|---|---|---|---|
| **① 外接记忆与统计** | 不是洞察力问题，是**记忆与算力**问题：人对自己历史的记忆是失真的，也不会统计 | 跨题台账：每个知识点「考几次 / 对几次」+ 可点开的逐题清单 | ✅ `knowledge_progress` / `mastery_logs` | 第 1 段「你的账」（真实数据：空集的性质 **9 考 1 对**） |
| **② 盲区的结构** | 单题他能看清，**跨题对齐**看不清：同一分叉位置反复出现、断点性质漂移、环节覆盖 | 跨题对齐结果：环节覆盖（哪些环节从未做对）+ 断点位置/性质的历史序列 | 🟡 数据全在（`segments` / `breakpoint` / `knowledgeUsage[].P`），**只差聚合** | 尚未做（下一步） |
| **③ 校准** | 元认知强＝自我监控强，但**监控本身会有系统偏差**；没有「你以为的 vs 证据」的对照就无法校准 | 学生先给一次自己的判断（归因/把握度），系统长期对照 | ❌ 从未采集（§7 拍板点 2，涉决策 048 冻结线） | 第 3 段候选（雏形） |

**推论一（优先级反转）**：报告的信息主体应按 **① ＞ ② ＞ ③ ＞ 对照 ＞ 建议** 排序，而不是"对照占最大篇幅、建议收尾"。
**推论二（价值自检）**：任何模块，若「学生自己也能得出」，就必须**可折叠、不占主体**，把位置让给「学生自己得不出」的模块。
**推论三（对 C4 的加强）**：元认知越强的用户，报告里 AI 的措辞应越少、机器台账应越多——**因为前者他自己会做，后者他做不了**。

### 2.6 文案规则：说人话，不许生造词（2026-09-26 定）

> 设计依据：为了避免「下结论」而生造中性抽象词（如「你在移动」），会同时违背更基本的一条——**前端文案说人话**。

**根因**：为了不越过「AI 不做裁判」，我把标题写成了中性的「你在移动」——结果违背了更基本的一条：**前端文案零术语、说人话**。
这仍是在"琢磨 AI 该怎么措辞"（＝泥潭），而不是"把事实本身说清楚"。

**术语 → 学生的话（唯一映射表，所有页面共用）**

| 判定术语 | 学生看到的话 |
|---|---|
| 起步即停 | 第一步没写出来 |
| 中途断 | 写到一半停了 |
| 收尾断 | 差最后一步 |
| `P=1` | 做对了 |
| `P≥0.8` | 基本做对 |
| `0<P<0.8` | 做了一半 |
| `P=0` | 没做出来 |
| 累计 `1/9` | 9 次里对过 1 次 |
| 日期 `09-18` | 9月18日 |

**规则**：
1. **禁止生造词**（"你在移动""知识迁移度""认知负荷"…）：学生日常不会说的词，一律换成他本来就会说的话。
2. **说明性小字不要写**（如"只列记录里的事实，不替你下结论"）——它本身就是诡异感的来源；事实摆出来，学生自己会判断。
3. **保留数字**：`P`、比例、次数这类原始量不要换成形容词（形容词会丢信息，且容易被读成评价）。
4. 不写"你真棒/加油/再加把劲"——指不回证据的话一律不出现（§0 A4）。

## 4. 验收标准（可观测，对齐 A3）

1. **动作率**：报告打开后，学生至少完成 1 个动作（点开证据 / 推翻一条 / 选一个归因 / 标记照做）→ 目标值需拍板
2. **可核验率**：报告中每句话都能指回证据指针（第几段/哪处原文），抽样人工核，**不允许出现指不回的话**
3. **可反驳成功率**：学生推翻后，系统改动可见（"已按你的更正更新"），且写入 `revisions`
4. **AI 话量**：证据不足（样本 <2 / `processAvailable=false`）时，AI 生成文字数应为 **0**（C4 可自动校验）

## 6. 与 8/30 那次重设计（`报告重设计-外部AI思考上下文.md` §6 七个开放问题）的关系

| 开放问题 | 镜子原则下的答案 |
|---|---|
| ① 报告应回答哪几个问题、什么顺序 | **顺序即 §1 的 C2**：先"我发生了什么"（第 0 段），再"差在哪"（第 1 段），再"更像哪种"（第 2 段），最后"做什么"（第 3 段） |
| ② 以题 / 错误类型 / 知识点为中心 | **以「题」为动线单位**（学生刚做完的就是题），知识点只作为**跨题聚合的证据**出现在台账与第 3 段 |
| ③ 给不给答案 | **不给**（保持），但**充分并排对照**——把"答案"变成"可自己看出来的落差" |
| ④ 认知科学隐式还是显式 | **隐式**：概念不作模块名（现状"断点/根因/钩子"直接当结构 = 已被用户否掉的过拟合） |
| ⑤ 聚合有没有价值 | 有价值，但**只能作为证据**（"这不是第一次在第 N 段断"），不能作为结论 |
| ⑥ 过程呈现：图片/文本/图文 | **图文结合**：原文分段可读，点击可看真实笔迹（`cropFileID`） |
| ⑦ 单题历史演化与主体的关系 | 并入第 1 段（作为"同位置的历次对照"），**不再独立入口** |
