## 2. 三个决定性事实

1. **学生使用高峰 = DeepSeek 闲时，DS 在线链路永远吃闲时价。**
   DS 高峰是 B2B 工作日白天（9–12 / 14–18）；本项目的学生是放学后 18:00–22:00 + 周末拍照诊断——**天然错峰**，在线链路不存在 DS 高峰惩罚。真正撞 DS 高峰的只有开发者自己白天跑批量/调试。

2. **GLM"常思考无法禁用"（报错 1210）决定了两类链路的分野：**
   - **thinking disabled 链路（判档/拆题/演化）→ GLM 硬伤**（视觉转录 0 产出已验证）；需实测 GLM 判定调用能否 disabled（9/1 前影子 AB 验证，这是决定性一问）
   - **thinking enabled 链路（报告生成/异议重诊）→ GLM 天然适配**（本来就要思考），且智能指数 57 vs 50、Terminal-Bench 84.3 vs 82.7 更优

3. **判定调用缓存命中率天然约 50–60%**（固定标尺全命中）；但远未到"命中率 >99% 反超"的程度，缓存项价差（GLM 0.115 vs DS 0.05）远小于输出价差（GLM 1.4/2.8 vs DS 4.5/9.0），**价格上 GLM 全面占优，唯一拦路虎是工程适配（事实 2）**。

## 4. 报告模块化 × 模型路由矩阵（未来架构）

现状：整份报告由**一个 Agent 循环（toolLoop）一次性输出**完整 JSON（overview / questions / weakpoints[]（四段式）/ secondaryPatterns）。
目标：拆模块、按模块路由 DS/GLM。**模块粒度 = 薄弱点**（四段式有依赖链：根因基于断点、钩子基于根因、检验呼应钩子，拆字段级会破坏一致性；`disputeModule` 已示范"一次调用生成整个薄弱点"）。

| 报告模块 | 生成方式 | 推荐模型 | 理由 |
|---|---|---|---|
| `questions` 每题展示 | **代码生成，0 LLM** | 无 | 纯数据映射（判定结果格式化），`assemble` 已有全部数据，不应让 LLM 转述 |
| `weakpoints` 薄弱点四段式（每薄弱点一次调用）| LLM，thinking enabled | **GLM** | 最有价值的深度分析：过程证据 + 依赖链 + 历史引用。智能上限最高处 = GLM 主场；五折输出 1.4 元 |
| `overview` 总览回执 | LLM，低思考/disabled | **DS**（GLM 备）| 短文本综合，输出 ~600 tok，单价差异小；DS 已跑通 |
| `secondaryPatterns` 次模式 | LLM，disabled | **DS** | 折叠预览短文本 |
| `questionEvolution` 演化（已独立 action）| LLM，disabled（现状）| **DS** | disabled 刚需，GLM 硬伤 |
| `disputeModule` 异议重诊（已独立）| LLM，thinking enabled（现状）| **GLM** | 四段式重生成，天然适配 |

**一句话：thinking enabled 的深度分析模块（薄弱点四段式/异议重诊）→ GLM；thinking disabled 的短文本模块（总览/次模式/演化）→ DS；纯数据映射模块（每题展示）→ 代码，不给钱。**

## 5. 工程要点（模块化落地必读）

1. **工具调用改为"数据前置"**：代码/DS 一次收集 4 个 RAG 工具结果 → 分发注入各模块 prompt。GLM 只做纯生成、不调工具。理由：规避 GLM function calling 兼容性未实测风险 + 规避每轮 thinking 成本放大。
2. **`toolLoop` 兜底必须改造**：现状"thinking 失败 → 降级 disabled 重试"对 GLM 是**死路**（GLM disabled 报 1210）。GLM 失败应改为重试 enabled，或直接走前端兜底按钮。
3. **模块化成本溢价约 70–80%**（方法论被每薄弱点重复携带 + 输出膨胀；粗算 0.0085 → 0.015 元/份）。溢价换：失败隔离（单薄弱点失败不影响整份）+ 模块级路由自由 + 局部重生成（异议只重建单薄弱点）+ 长尾缓存复用。按"混用"诉求，此溢价必须付。
4. **模块依赖顺序**：weakpoints 先生成 → overview.coreHint 引用主模式名 → secondaryPatterns。questions 纯代码。
