## 四、治理规则（定稿，2026-08-17）

### 4.1 命名规则

- **主体精炼名词短语，≤6 字优先**：「集合」「子集」「空集」「韦达定理」
- **禁止**：句子（带谓语长串，如「『或』与『且』在集合运算中的逻辑辨析」）、括号注释（如「半角公式（平方形式与根号形式）」）、引号（『』""）
- **说明放 `concept.source_text`**：公式、条件、边界、例子一律不进 name
- **判定提问**：name 应能直接回答「学生不会的这一个点是什么」

### 4.2 类型执行（判定式提问法）

| type | 判定提问 | 合格例 | 不合格例 |
|------|---------|--------|---------|
| definition | 能回答「什么是 X」 | 集合、子集、命题 | Venn 图在集合运算中的应用（是应用） |
| property | 能回答「X 有什么性质/定理」 | 确定性、互异性、空集的性质 | 空集是任何集合的子集（句子→并入空集） |
| notation | 符号表示 | 常用数集、逻辑蕴含符号 | —— |
| method | 能回答「怎么做 X」 | 列举法、配方法、求交集的方法 | 三角学与天文学（阅读栏目） |
| example | 典型案例（仅教学价值显著） | 教材典型例题 | 人体节律周期模型（应用实例） |

**判别句/关系辨析**（「属于与包含的区别」「或且逻辑辨析」）不是独立知识点——并入相关节点 source_text。

### 4.3 粒度规则

1. **叶子 = 一个可独立考核的点**（能单独出题、单独不会）
2. **并列知识点各自保留，不合并**：可各自独立考核的公式/性质/方法并列时（如两角和/差的正弦/余弦/正切 = 6 个并列公式；φ/ω/A 对图象的影响 = 3 个并列变换；积化和差 vs 和差化积 = 2 个并列公式）**逐个保留独立节点**——精炼的是名字，不是合并节点
3. **聚合只针对**：同一知识点的不同表述/推导过程/应用实例（如「从 C(α−β) 到全部公式的推导链」并入公式节点；「摩天轮/潮汐建模」并入三角建模）——推导过程、研究思路、教材阅读栏目、应用实例不做节点
4. **每节节点数 5~12**（宁缺毋滥；仅当真的可聚合时才少）
5. **全局去重**：同名/同义节点禁止（「集合相等」1.1/1.2 重复必须合并——这是真重复，不是并列）

### 4.4 第 0 章（预备知识）

- **命名**：「第0章 预备知识」（对齐人教 A 版教材）
- **path**：`["数学", "初高衔接", "第0章 预备知识", "0.x …"]`
- **收容**：工具性、跨章节、初中前置知识——一元二次方程 / 一元二次方程的解法 / 判别式 / 韦达定理 / 因式分解 / 配方法 / 分式运算 / 根式运算 / 绝对值 / 一次函数 / 二次函数基础
- 旧 schema 10 条中的工具节点迁入此处

## 七、节点判定标准（定稿：WWH 模型，源自 21 项技术·知识类别研判）

**什么是知识点（建节点）** = WWH 的 **What（知识本体，5 类元素）**：

| 要素 | 含义 | 例 |
|------|------|-----|
| 定义 | 概念定义 | 集合、子集、空集 |
| 表示 | 符号/图形表达 | 常用数集、若p则q形式 |
| 性质 | 固有特点与规律 | 确定性、互异性、韦达定理 |
| 操作 | 对知识的运算/变换（可独立考核） | 配方法、列举法、五点法作图 |
| 关系 | 概念间边界/归属/分类位置 | 属于与包含的关系 |

**什么不是知识点（不建节点）**：

| 类别 | 归属 | 例 |
|------|------|-----|
| 推导链 / 推导方法 | WWH **Why（来源）**——学生自己推，不是知识本体 | 从 C(α−β) 到全部公式的推导链 |
| 知识来源（需求/发现） | Why | 负数是为了解决相反意义的表示 |
| 应用实例 / 建模实例 | WWH **How（应用）**——归 A/题型 | 摩天轮建模、潮汐水深、声音三角函数 |
| 研究思路 / 思想 | 非本体 | 从特殊到一般、换元思想 |
| 教材阅读栏目 | 非知识点 | 阅读与思考 |
| 步骤细化（主知识的应用细节） | 并入主节点 source_text | 辅助角化简的步骤、符号判定方法 |

**判定口诀**：这段内容回答的是「这是什么」（What→建）、「它从哪来」（Why→不建）、「它能干嘛」（How→不建）。推导、应用、来历都不是学生要单独掌握的 K 知识点。
