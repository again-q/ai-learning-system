> 理论构建：again-q
> 版本：v3.1（2026-08-18）
> 状态：✅ 已定稿
> 定位：课后辅助诊断工具，不代替学校

## 一、核心命题

用一个可量化的、可操作的模型，让一个初高中生知道自己"到底哪里不会"、"为什么不会"、"下一步该做什么"。

三个子问题：
1. **"掌握"到底指什么？** — 不只是"会不会"，而是"会到什么程度"
2. **怎么把它变成可测的数字？** — 从学生日常做题数据中提取五个维度的信号
3. **测出来之后怎么用？** — 输出可操作的诊断报告和行动建议

>
> ⚠️ **追加（2026-09-25，用户拍板）· 本框架的最终目的 —— 最高判据**
>
> **我们不是要 AI 给出一个正确的结论，我们要的是——学生看完这条输出之后，自己动了一下，而且那个动作是他自己判断出来的。镜子越用越自立，裁判越用越依赖。如果哪天他不用打开报告就知道自己哪儿薄，这个项目才算成功。**
>
> 由此推出三条不可让渡的性质（任何设计与参数取舍先对它，对不上就不做）：
> 一、**可核验**：每句话都能指回卷面上的具体位置；指不回去的句子不许出现。
> 二、**可执行**：结论后面必须跟一个下次能做的动作；只有结论不算完成。
> 三、**可反驳**：学生能推翻，且推翻之后系统必须改。
>
> 判断归属：**对错是事实，归学校/官方；过程与动作归 AI；掌握度不向学生抛结论**——AI 不做裁判，做镜子。
> 展开与工程检查点见《AI 产出物 —— 第一性原理》（`doc/architecture/AI产出物-第一性原理.md`）。
>
> ⚠️ **追加（2026-10-02，用户拍板）· 服务对象与核心命题已重定 —— 见 `doc/TARGET.md`**
>
> 按决策 016（本文件只追加、不篡改原文），**上文「到底哪里不会 / 为什么不会」的表述不删改**，仅在此标注其**适用范围已收窄**。
>
> **决策 059 的重定**（依据：[`doc/TARGET.md`](../TARGET.md)）：
> - **服务对象收窄为「卡在瓶颈上的高分段学生」**；低分段学生**前期不做**。
> - **核心命题由「你哪里不会」改为「你哪里会被扣分」** —— 学生基本都会，丢分在**步骤书写 / 逻辑严谨 / 边界情况**，他要的是**阅卷老师的眼睛**，不是再教一遍知识。
> - **过程审阅只做解答题**（实测：选择 20＋填空 20＋其他 2 共 42 道，`processAvailable=true` **0** 道；解答 19 道 **100%** 有过程）。
> - **「做对的题」比「做错的题」更重要** → 只审错题漏掉了目标用户最值钱的部分。
>
> **对本框架的连带裁决**：K（知识点用对率）对目标用户**区分度≈0**（他基本都会）→ **降为副指标**，用途转为"确认他都会、可以不管"（证否）；**A 升为主指标之一**，信号源需重定义为**过程质量**；Q/S/T 维持冻结。
> **五维框架本身保留，但产品表达不再以五维为主** —— 学生看不懂"五维"，他看得懂"这一步会扣分"。
>
> **不冲突**：本节三条不可让渡的性质（可核验 / 可执行 / 可反驳）**继续是最高判据**，且过程审阅比旧形态**更贴合**它（给了标准解法对照，"学生能不能推翻"才有落点）。

## 二、核心 Pipeline

所有维度的计算基于统一的数据管道：

```
题目作答记录（含过程证据）
    ↓
题目类型判定（回忆类 / 单元内应用 / 跨单元应用）
    ├─ 所有题目 → K 维度更新（知识点粒度，§4.4 修订）
    ├─ 单元内应用类题 → A 维度更新
    ├─ 跨单元应用类题 → A + T 维度更新
    ├─ 所有题目 → S0 波动指数（客观计算）
    └─ 高价值题目 → 思维链采集 → Q 评分 + S1~S4 回溯
    ↓
更新五维分数 → 输出诊断报告
```

> 注：Pipeline 的工程执行动作（采集、判定、存储、检索）见《五维工程实现规范》§一。

**核心原则**：
1. 每个维度使用互不重叠的数据源，避免维度间的信号污染。
2. K 从所有已判定题更新（知识点粒度：每个知识点用自己环节的难度×作答，§4.4），A/T 仅从应用类题更新，Q 仅从思维链更新，S0 全量自动计算，S1~S4 仅从回溯更新。
3. 一道题可能触发多个维度的更新（例如跨单元应用类题同时触发 A 和 T），但每个维度的计算使用各自独占的信号。

## 三、五维能力向量

```
M = (K, A, T, Q, S)
```

| 维度 | 对学生说 | 认知本质 | 粒度 | 数据源 | 覆盖率 |
|------|---------|---------|------|--------|--------|
| K | 知不知道？ | 陈述性记忆 | 知识点（树状聚合） | 难度×过程分（加权得分法） | 稀疏（仅回忆类题） |
| A | 会不会用？ | 程序性知识流畅度 | 教材单元 | D×η（有效刺激量），A/U框架 | 全量 |
| T | 能不能串？ | 跨单元结构识别 | 全局（每学生一个） | W×D×r，T/U框架 | 稀疏 |
| Q | 会不会学？ | 元认知（觉察与调整） | 全局 | 思维链（独占） | 稀疏 |
| S | 稳不稳？ | 失常模式诊断 | 全局 | S0自动计算 + S1~S6回溯自报 | 全量 |

> ⚠️ **追加（2026-09-25，用户拍板）· K / A / T 的内涵精确化（大白话版）**
>
> 上表「对学生说」列**保留不动**（K 知不知道？/ A 会不会用？/ T 能不能串？），这里只补原文缺的那一件东西：**在什么情境下**。补上之后三个维度才真正不重合。
>
> **一句话记住：K ＝ 有没有 ｜ A ＝ 熟不熟 ｜ T ＝ 会不会变通。**
>
> | 维度 | 大白话问句 | 什么时候算它 | 什么时候**不算**它 |
> |---|---|---|---|
> | **K** | 这东西**你知道吗**？ | 能**直接说出 / 认出**（复述、辨认、归类），**不需要解题** | 做题对不对、题难不难、稳不稳——都与 K 无关 |
> | **A** | 这类**见过的题**你**熟吗**？ | 在**练过的题型**上又快又顺：自动 / 半自动调用，不需要重新分析结构 | **题难不算 A 高**（难题用标准解法流畅写完 ≠ T 高）；**自创新解法不算 A**（属 T）；准确度也不归 A（对错归事实层） |
> | **T** | **没见过的题**你能**自己想办法**吗？ | **重组知识 / 自造解法 / 识别深层结构**（新颖、复杂、不良结构） | **跨单元只是它的一大类**，不是它的定义；题难但走标准解法也不算 T |
>
> **术语对应**：
> - **K** = 长期记忆里事实 / 概念 / 程序性信息的**可提取程度**（只关「是什么 / 为什么」）
> - **A** = **熟悉且结构良好**情境下，自动 / 半自动调用知识完成**标准任务**的**熟练度与效率**
> - **T** = **新颖 / 复杂 / 不良结构**情境下，识别深层结构、**重组**知识、**自造**解法的能力（适应与创造）
>
> **边界三条（防再次重合）**：
> 1. **K 与难度无关**：默写一个定义没有「难度」可言 → **题目难度不得作为 K 的证据**。
> 2. **A 与难度不直接关联**：难度只作**分层条件**（在同难度层内比熟练度），不作证据。
> 3. **知道「操作是什么」= K；「自动执行操作」= A**（§4.7 把「操作」整体归 K，须按这条读）。
>
> **与 §4.4 / §5.5 / §6.4 的关系**：三个现有算法的数据源里都直接乘了难度（K 用 `D_kp`、A 用 `D×η`、T 用 `W×D×r`），按本条属于**错位**，另行出「⚠️ 修订」块处理；K 的新证据口径（可否直接提取）与算法**尚未定稿**，不在此写死。

## 四、K — 知识掌握

### 4.1 本质定义

K（知识掌握） = 知识点在学生的长时记忆里是否存好。

它不是"会不会用"（那是A），也不是"能不能串"（那是T），而是单纯的"知不知道"——概念定义记住了吗？公式背熟了吗？性质理解了吗？

### 4.2 三层结构

| 层 | 内容 | 计入K总分 |
|---|------|---------|
| 知识层 | 概念定义、教材方法 | ✅ 是 |
| 模型层 | 题目模型、解题框架 | ❌ 参考输出，不参与评分 |
| 思想方法层 | 思维技巧、数学思想方法（含阅读与思考） | ❌ 参考输出，不参与评分 |

模型层和思想方法层作为参考信息输出，帮助诊断"学生知道概念但不会用模型"的情况，但不影响K值的计算。

> ⚠️ **修订（2026-08-17）**：模型层（题目模型）仍不参与 K 评分；其工程用途（生成题型结构供历史检索）见《五维工程实现规范》§2.3。

### 4.3 树状结构

K维度的数据结构是一棵树：

```
学科
├── 单元
│   ├── 话题（如"二次函数"）
│   │   ├── 知识点A（如"顶点式"）
│   │   ├── 知识点B（如"一般式"）
│   │   └── 知识点C（如"交点式"）
│   └── 话题（如"一次函数"）
│       ├── 知识点D（如"斜率"）
│       └── 知识点E（如"截距"）
```

- **叶子节点**（精细知识点）：用加权得分法 S_k/D_k 计算掌握度
- **父节点**（话题/单元/学科）：用加权平均聚合子节点的掌握度

### 4.4 叶子节点算法：加权得分法

**基本公式**：
```
每道题的贡献 = 难度(D) × 过程分(P)
知识点累计得分 S_k = Σ 贡献
知识点累计难度 D_k = Σ 难度
掌握度 = S_k / D_k
```

**掌握度的本质**：掌握度 = S_k / D_k = Σ(D × P) / Σ D。这是一个加权平均——每道题的过程分 P，按难度 D 加权，求平均。换句话说：掌握度 = 所有做过题目的平均表现，但难题权重更高。

> ⚠️ **过去版本（2026-08-17 起废弃）**：上述 D×P 中的 D 为「整题难度」、P 为「整题过程分」——信号源是题目整体，不符合第九章独占信号源原则：学生对某个知识点的作答被整题难度稀释，且无法区分「知识边界缺失」与「思路问题」。
>
> **现行版本（2026-08-17 用户拍板）**：K 更新改为**知识点粒度**：
> - 一道题拆出它考查的若干知识点，每个知识点有自己的**环节难度 D_kp** 和**环节作答 P_kp**
> - 贡献 = Σ D_kp × P_kp，累计到对应知识点：S_k += D_kp×P_kp；D_k += D_kp；掌握度 = S_k / D_k（公式不变，粒度加细）
> ⚠️ **修订（2026-09-25，用户拍板，决策 052）· K 的记账单位与公式**
>
> **记账单位 = 图谱最细一层的知识点节点**（那些节点自带类型：定义 / 性质 / 表示）。**父节点不由判定直接写**，只能由子节点聚合（见 §4.5 修订块）。
>
> **公式（最细节点）**：
> ```
> K_叶 = 该知识点「被用对」的次数 / 该知识点「被考察到」的次数
>        分子 = 环节作答 P_kp = 1
>        分母 = P_kp = 1 的次数 + 概念性错（errorLevel = concept）的次数
>        不计入：rule（步骤/分类漏 → 归 A）、skill（算错抄错 → 归 S）
> ```
>
> **难度 D 不再进入 K**：上方 2026-08-17 修订块里的 `S_k += D_kp×P_kp；D_k += D_kp` **就此作废**（理由见决策 049：难度是情境条件，不是证据）。
>
> **为什么单点允许到 100%**：「知道」没有「知道 60%」——最细一条定义他会就是会。而「只能应付简单题」由 **A（熟练度/难度分层）** 与 **T（变通）** 表达；「简单题全对刷不出满分」由 §4.5 的父节点聚合保证。
>
> **连带冲突标注**：本节 2026-08-17 那两块里有两句已被本修订取代——① 「按难度 D_kp 加权」→ 难度退出 K；② 「所有已判定题均可触发 K 更新」→ 改为按 `errorLevel` 分流：**只有概念性错（concept）才扣 K**，rule/skill 不计入。
> - **P_kp 三档**：1 = 用对；0.5 = 用了但漏边界/不完整（如漏特殊值验证、多选漏特殊情况）；0 = 该环节缺失/全错
> - 信号源 = 该知识点在本题的难度 × 学生在该环节的作答——每个知识点独占自己的信号；边界陷阱题（知识边界缺失）自动落入该知识点 P_kp=0.5/0，不再被整题 P 稀释
> - 工程执行（知识点拆解、判定锚点、存储）见《五维工程实现规范》§2
>
> ⚠️ **修订（2026-10-03，用户拍板，决策 060）· K 的定义与公式（现行版本）**
>
> ### 定义（用户原话）
> > **K = 在一定难度的情景下，从情境中识别出这个知识点的能力**
> > **A = 在已知需要用这个知识点的前提下，完成一系列步骤并得出正确答案的能力**
>
> **分界线是「前置条件」，不是难度高低**：
> - **K 的题**：题目**没有明说**要用这个知识点，得自己认出来 → 认不出即失败
> - **A 的题**：**已经知道要用它了**（题目说了，或 K 那一步已经过了）→ 接下来会不会做
>
> 「概念不清」被这两句拆成两件可数的事：**不知道这个知识点管哪类问题 = K**；**知道它管用但做不下去 = A**。
> 两者的干预方式不同（补知识的边界 vs 练执行），所以必须分开记账。
>
> ### 公式
> ```
> K_叶 = Σ(难度权重 × 正确次数) / Σ(难度权重 × 总次数)
>
> 难度权重：简单 0.1 / 中等 0.2 / 困难 0.7
> ```
>
> **权重依据（用户推导，不是调参）**：真实卷子的难度配比是 简单 70% / 中等 20% / 困难 10%；
> 难题最能反映能力，所以**权重方向反过来** —— 越能反映能力的权重越大。
>
> ### 判据 R：形式的正确性
> - **R = 1**：这个知识点的形式在笔迹里出现了，且形式正确
>   - **等价变形算对**（例：`½m(v₂²−v₁²)` 与 `½mv₂²−½mv₁²` 同义，**后者证明他看懂了结构，不是背字符串**）
>   - 不要求一字不差，不要求变量符号完全一致（意义对应即可）
> - **R = 0**：形式整行没出现（没认出来）
>
> ### 读法
> ```
> K × 100 = 一套真实难度配比（70 简单 / 20 中等 / 10 困难）的卷子，他能拿多少分
> ```
> 样本量 = Σ(难度权重 × 总次数)，与 K 一起显示 —— **频率口径，可反推回每次观测**。
>
> ### 已知取舍（用户拍板接受）
> **刷简单题能把 K 刷到 100**（`scripts/k-easy-only.mjs` 实测：2100 道简单题全对 → K=100%）。
> **不做过滤**——产品不是防作弊系统，只求正常情况下测得准。
>
> ### 与旧版的关系
> | 项 | 052（作废） | 060（现行） |
> |---|---|---|
> | 分子 | 只认「完全用对」，`P_kp = 0.5` 那档蒸发 | 认「形式正确」，等价变形算对 |
> | 难度 | 完全不进（决策 049「难度是情境不是证据」） | **进权重**（配比来自真实卷子 7:2:1，方向反过来） |
> | 分母 | 只收「用对 + concept 错」，rule/skill 不进 | **全收**（凡被考察到的都算一次观测） |
> | 读法 | 无明确读法 | **K × 100 = 卷面分** |
>
> ⚠️ **⚠️ 连带冲突：决策 049「难度不进 K」就此作废。** 049 的理由是「难度不能当证据扣分」——
> 这一点仍然成立：**难度不作为正确与否的判据**。但难度作为**聚合时的权重**是另一件事，
> 二者不冲突。060 = 难度不进判据、但进权重。

**难度 D 的判定（5维度加权）**：

| 维度 | 低分 | 高分 |
|------|------|------|
| 知识复杂度 | 单步套公式 | 多步+跨知识点 |
| 思维深度 | 直接套用 | 逆向/构造 |
| 陷阱密度 | 直白无坑 | 多陷阱/分类讨论 |
| 计算强度 | 口算级别 | 复杂运算 |
| 陌生度 | 常规题 | 新题型 |

D 的范围：0.01~0.99。

**过程分 P 的判定（4档，2026-08-14 起废弃，仅作历史语义锚点）**

> ⚠️ **过去版本（2026-08-14 起废弃）**：P 原为离散四档 {0, 0.3, 0.5, 1.0}，下表即旧规则，**仅作语义锚点保留，不再作为钳制规则**。
>
> **现行版本（2026-08-14 用户拍板）**：P 改为**连续值 0~1**，语义 = 过程与正确答案的距离：
> - 完全正确且答案对 = 1.0
> - 答案错但过程几乎完整（最后一步错/抄错）= 0.8~0.95
> - 中途偏航但思路对 = 0.4~0.7
> - 只有思路无结果 = 0.2~0.3
> - 空白/完全跑偏 = 0
> - **判错时 P < 1**（1.0 只留给完全正确）；选填无过程可分，判错 P=0：

| 分数 | 描述 |
|------|------|
| 1.0 | 完全正确，思路清晰 |
| 0.5 | 部分正确 / 正确但思路模糊 |
| 0.3 | 错误但有正确思路 |
| 0 | 完全错误 / 空白 |

**更新时机**：仅回忆类题（默写公式、复述定义、判断对错）触发K维度更新。应用类题不更新K。

> ⚠️ **过时（2026-08-17 废弃）**：回忆类题在现实题海中极稀缺（几乎没有纯默写公式的题），导致 K 无样本可更新。且「整题 D×P 挂主知识点」语境下，用题目难度算学生知识掌握确实依赖回忆类前提。**粒度修订后该限制不再需要**：所有已判定题均可触发 K 更新——按知识点拆解后，只要某知识点环节得出 D_kp 和 P_kp 就累计（见 4.4 修订块）。

**超纲规则**：判定为超纲的题目，做对了→正常更新（S_k和D_k都加）；做错了→不计入D_k（不降掌握度）。

### 4.5 父节点聚合：加权平均

**公式**：
```
父节点掌握度 = Σ(w_i × 子节点掌握度_i) / Σ w_i
```

**权重 w_i 的决定因素**：
- 知识点在话题中的核心程度（如"顶点式"比"一般式"在二次函数话题中更核心）
- 高考/大考的考查频次
- 学科大纲中的课时分配

权重由学科知识图谱内置，静态维护。
> ⚠️ **修订（2026-09-25，决策 052）· 父节点聚合从「纸面公式」变成「唯一来源」**
> - **判定端只允许写最细一层节点**；父节点的 K **必须**由子节点聚合得到，**禁止**判定直接写父节点。
> - **现状偏差（2026-09-25 云库实测）**：66 条 `knowledge_progress` 里有 **8 条直接记在父节点上**（「集合」12 次、「子集」20 次），且聚合公式**从未实现**。
> - 权重 `w_i` 仍按本节「图谱内置、静态维护」；图谱还没存该字段时**先等权（w = 1）跑通**，再由图谱治理线补权重。

**聚合层级**：
```
学科总掌握度 = Σ(w_单元 × 单元掌握度) / Σ w_单元
单元掌握度 = Σ(w_话题 × 话题掌握度) / Σ w_话题
话题掌握度 = Σ(w_知识点 × 知识点掌握度) / Σ w_知识点
```

每一层的权重都由知识图谱内置，反映该节点在上一层中的重要程度。

### 4.6 输出格式

**4档制**：

| 档位 | 掌握度范围 | 说明 |
|------|-----------|------|
| 🟢 掌握 | ≥ 0.80 | 知识点牢固，可进入下一阶段 |
| 🟡 巩固 | 0.60~0.79 | 基本掌握，需要定期复习 |
| 🟠 薄弱 | 0.40~0.59 | 掌握不牢，需要针对性练习 |
| 🔴 紧急 | < 0.40 | 未掌握，需要重新学习 |

**话题级输出**：
- 话题整体掌握度 = 各知识点掌握度的加权平均
- 同步输出该话题下最薄弱的1~3个知识点

### 4.7 七要素归属

| 要素 | 归属维度 |
|------|---------|
| 定义、性质、操作、关系、表示 | K 维度 |
| 应用 | A 维度 |
| 来源 | Q 维度 |

### 4.8 参数总表

| 参数 | 值 | 说明 |
|------|-----|------|
| D范围 | 0.01~0.99 | 5维度加权平均 |
| P | 0~1 连续（2026-08-14 起；过去版本为档位 1.0/0.5/0.3/0，已废弃，见 §4.4 标注） | 过程距答案的距离 |
| P_kp | 0/0.5/1 三档（2026-08-17 起） | 知识点环节作答：1=用对；0.5=用了但漏边界/不完整；0=该环节缺失/全错 |
| 掌握档位边界 | ≥0.80掌握 / 0.60巩固 / 0.40薄弱 / <0.40紧急 | 4档制 |
| 父节点聚合 | 加权平均 | 权重由知识图谱内置 |

## 五、A — 应用能力

### 5.1 本质定义

A（应用能力） = 运用所学知识解题的能力指数。

它不是"做对的概率"，也不是"知识点的掌握度"，而是一个人运用所学知识解决问题的水平高低。

### 5.2 与K和T的区别

| 维度 | 本质 | 举例 |
|------|------|------|
| K | 知不知道这个公式（陈述性记忆） | 能默写F=ma |
| A | 能不能识别出该用这个公式并正确运用（程序性知识流畅度） | 看到斜面题知道用F=ma |
| T | 能不能把多个公式串起来（跨单元串联） | 把F=ma和匀变速直线运动公式结合起来解题 |

### 5.3 两层结构

| 粒度 | 名称 | 数量 | 含义 |
|------|------|------|------|
| 单元级 | 单元A | 每单元一个 | 该单元内的应用能力指数 |
| 全局级 | 全局A | 每学生一个 | 所有单元A加权聚合，反映整体应用能力水平 |

全局A不是独立于A的另一个维度，而是A维度在全局层面的聚合产物。

### 5.4 核心思想

1. A是能力指数，不是概率 — 它随着有效练习而增长，不会围绕一个固定值波动。
2. 学习是分单元进行的 — 每个单元独立维护自己的A和U，新单元的A从初始值开始。
3. A的增长受上限U约束 — A不能超过U，U本身是浮动的，由解题质量决定。
4. 路径质量决定增速和上限走向 — 暴力计算的人A涨得慢，U不涨甚至下浮；使用本质解法的人A涨得快，U持续上浮。

### 5.5 单元A核心算法

**每个单元维护的数据**：

| 变量 | 含义 | 初始值 | 范围 |
|------|------|--------|------|
| A | 当前能力指数 | 0.30 | [0, U] |
| U | 当前能力上限 | 0.50 | [A, 1] |
| N | 总观测次数 | 0 | 整数 |

**有效刺激量 E**：
```
E = D × η
```
其中：
- D（题目鉴别力）：分析题目文本，复用K维度的5维度（知识复杂度、思维深度、陷阱密度、计算强度、陌生度），权重调整。范围0~1。
- η（路径质量系数）：分析学生步骤文本，判断解法是否接近本质。范围0.4~1.0。

取值规则：
- 做对时：E > 0（正向刺激）
- 做错且是A问题：E < 0（负向刺激，取 -D × η）
- 做错且是K/S问题：E = 0（不更新A）

**上限U的更新**：
```
if E >= 0.5 and η >= 0.7:
    # 上浮：学生展示了本质解法，有突破潜力
    U += 0.05 × (1 - U)

elif 连续5道题 η <= 0.6:
    # 下浮：学生持续暴力计算，挤压虚假上限
    U -= 0.03 × (U - A)
```

上浮的语义：当学生展示出"这道题我用了接近本质的解法，且题本身鉴别力够"时，我们认为他有能力突破当前上限，U缓慢上浮。

下浮的语义：如果学生长期只用暴力计算，他的真实上限其实到不了U当前值——U应该向下收敛到A，把"虚假上限"挤掉。

**能力指数A的更新**：
```
if E > 0:
    ΔA = 0.25 × E × (U - A)
    A = min(A + ΔA, U)       # 硬约束：A不超过U

elif E < 0:
    ΔA = 0.25 × |E| × (U - A)
    A = max(A - ΔA, 0)       # 不低于0
```

ΔA = α × E × (U - A) 的含义：
- α（学习率）：控制更新灵敏度，α=0.25
- E（有效刺激量）：这次练习的质量
- (U - A)：剩余上升空间——A离上限还有多远
- 三个因子相乘：任何一个因子小，更新量就小；三个因子都大，更新量才大

**输出精度**：全精度计算，对外输出保留两位小数（百分位），第三位四舍五入。
> ⚠️ **修订（2026-09-25，用户拍板，决策 055）· A 的证据与公式**
>
> **一句话**：A 刻画的是「**把知识用出来的熟练度**」。我们**没有时间/尝试次数**，所以只能测它的**痕迹**——对错（P）、难度情境（D）、过程形态（是否卡壳）。
>
> **观测值 s（0~1）**：
> ```
> s = P × (0.6 + 0.4·D) × q
>   解答题：q = 1 − 断段数 / max(1, 总段数)        （过程卡壳 → 打折）
>   选填题：q = 1（无过程可看）
> ```
> - **P = 0 → s = 0 → A 必跌**（做错就是没用出来）
> - **难度只作情境校准**（同一份"做对"，难题上更值钱），**不进公式主体**——符合决策 049「难度是情境条件、不是证据」
> - **跳步不罚**：熟练的人本就不写全；漏写的后果已由 P 罚过，不重复罚
>
> **谁进 A（按 `errorLevel` 分流）**：
> | `errorLevel` | 进 A | 进 K | 归 S |
> |---|---|---|---|
> | **skill**（算错 / **抄错**） | ❌ | ❌ | ✅ |
> | **concept**（概念没懂） | ✅ 负向 | ✅ 负向 | — |
> | **rule**（步骤 / 方法错） | ✅ 负向 | ❌ | — |
> 「**抄错归 S**」的依据是本文件 §8.1（S = 实际表现与真实能力的**偏差**）；且**单次抄错判不出 S**——S 本质是**方差**，要靠跨题比较（见 §8.4 S0 波动指数）。
>
> **更新公式**（学习率与起点沿用本节原文）：
> ```
> ΔA = 0.25 × (s − A) × (U − A)        ← 上式 E 的位置由 (s − A) 承担
> A  = clamp(A + ΔA, 0, U)
> U  : 连续 2 次 s ≥ 0.8 → U += 0.05(1−U)
>      连续 5 次 s ≤ 0.6 → U −= 0.03(U−A)
> ```
> **与本节原文的关系**：原文 `E = D × η` 的两处问题——① D 不该乘进 A（决策 049）；② 只由 η 构成的观测值**把"对错"漏掉了**（用户质疑「怎么能不管对不对」）。本修订把对错（P）与过程形态（q）显式写进 s，D 降为情境校准。
> **连带**：A 的**粒度仍为单元级**（不拆节点账本，理由见决策 054）；条目级不单独立账，本体与方法只通过 s 的构成影响 A。

### 5.6 单元A的行为特征

| 阶段 | N范围 | A的行为 | 原因 |
|------|-------|---------|------|
| 入门期 | 1~5 | 快速拉升，每跳0.02~0.04 | (U-A)大，E即使中等也能推动明显增长 |
| 快速拉升期 | 6~15 | 持续上涨，偶有震荡 | 高质量练习推动U上浮，A追赶 |
| 平台期 | 16~25 | 涨速放缓，A接近U | (U-A)变小，ΔA自然减小 |
| 突破期 | 26~35 | 突然跃升（开窍感） | 本质解法触发U上浮，A重新获得增长空间 |
| 精进期 | 36~50 | 微幅波动，缓慢爬升 | (U-A)趋近0，U涨速极慢 |
| 稳定期 | 50+ | 基本不动，收敛于U | A和U几乎重合，能力达到当前上限 |

### 5.7 全局A

**本质定义**：全局A = 由各单元A加权聚合而成的综合指标，反映学生整体的应用能力水平。

全局A较高不仅说明已学单元的应用能力强，也隐含了学新单元的迁移潜力（学习能力的间接体现）。

**各单元权重**：
```
w_i = importance_i × confidence_i × stage_i
```

- importance_i（静态）：由学科大纲内置，反映高考占比/单元核心度。不需要和为1，归一化时处理。
- confidence_i（动态）：由该单元的观测次数 N_i 决定。

```
confidence_i = 1 - e^{-0.1 × N_i}
N=10 → confidence≈0.63
N=20 → confidence≈0.86
N=50 → confidence≈0.99
```

- stage_i（动态）：由最近M次上传（M=20）中该单元题目的占比 active_i 决定。

```
stage_i = 0.7 + 1.0 × active_i
active_i = 0 → stage = 0.7（老单元基础权重）
active_i = 1.0 → stage = 1.7（正在密集学）
```

**不参与聚合的单元**：
- N_i = 0（完全没学过）→ confidence=0 → w_i=0
- 已结课且长期未碰的单元：active=0 → stage=0.7，仍有基础权重，不会完全消失

**聚合与平滑**：
```
w_i' = w_i / Σw_j          # 归一化
聚合值 = Σ(w_i' × A_i)     # 加权平均

全局A_new = 全局A_old + 0.25 × (聚合值 - 全局A_old)   # EWMA平滑
```

**初始值**：首个有数据的单元的A值。

**输出条件**：有效单元数 ≥ 2 且 总N ≥ 15 时，输出全局A。否则只输出当前单元A。

### 5.8 参数总表

| 参数 | 值 | 说明 |
|------|-----|------|
| α | 0.25 | 学习率 |
| δ_u | 0.05 | U上浮速率 |
| δ_d | 0.03 | U下浮速率 |
| λ | 0.1 | confidence(N)衰减率 |
| base | 0.7 | stage(active)老单元基础权重 |
| k | 1.0 | stage(active)活跃加成系数 |
| α_g | 0.25 | 全局A平滑率 |
| — | importance_i | 大纲内置，静态权重 |

## 六、T — 迁移能力

### 6.1 本质定义

T（迁移能力） = 学生识别跨单元深层结构、组合不同单元知识解题的全局能力。

它不是"在某个结构上的迁移能力"，而是这个人本身的属性——无论给他什么跨单元题，他都能更快地识别出深层结构。

### 6.2 核心属性

- **全局的**，不依赖单元（不像A每个单元一个）
- **初始值低**（0.10），因为跨单元综合题通常在学完多个单元后才出现
- **样本量少**（跨单元题远少于单元内题），所以更新更保守

### 6.3 与A维度的关系

| 维度 | 粒度 | 数量 | 初始值 | 更新触发 |
|------|------|------|--------|---------|
| A | 单元级 + 全局聚合 | 每单元一个A + 一个全局A | 0.30 | 单元内题 |
| T | 全局级 | 每学生一个 | 0.10 | 跨单元综合题 |

### 6.4 数据源

| 信号 | 来源 | 说明 |
|------|------|------|
| W（跨类型权重） | 知识图谱判断 | 反映跨单元的类型和难度 |
| D（题目鉴别力） | 题目文本分析 | 复用A维度的D |
| r（解题质量系数） | 学生深层结构识别（需引导/对话） | 0~1，反映学生是否识别了深层结构 |
| T_shown | 本次表现推断 | 由r和作答结果共同决定 |

> 判定执行见《五维工程实现规范》§四（T 维度暂缓）。

### 6.5 核心算法

**每个学生维护的数据**：

| 变量 | 含义 | 初始值 | 范围 |
|------|------|--------|------|
| T | 当前迁移能力指数 | 0.10 | [0, TU] |
| TU | 当前迁移能力上限 | 0.60 | [T, 1] |

**有效刺激量 E_t**：
```
E_t = W × D × r
```

**T_shown（展现出的能力）**：T_shown 根据学生的作答结果和思维链综合判断。它不是"当前T值"，而是"这次表现展现出的能力水平"。

| 表现 | T_shown |
|------|---------|
| 竞赛压轴题做对 + 说清结构 | 0.95~0.98 |
| 高考压轴题做对 + 说清结构 | 0.80 |
| 高考压轴题做对 + 说不清结构 | 0.50 |
| 部分对 + 结构方向对 | 0.30 |
| 完全做错 + 结构没认出 | 0.05 |

**TU的更新**：

上浮触发（两个条件同时满足）：
1. 最近3道跨单元题中，有任意一道的 T_shown > TU × 1.1
2. 最近3道跨单元题的 T_shown 平均值 > TU

上浮幅度：
```
TU_new = TU_old + 0.1 × (T_shown_max - TU_old)
```

下浮触发：最近3道跨单元题的 T_shown 平均值 < TU × 0.7

下浮幅度：
```
TU_new = TU_old - 0.09 × (TU_old - avg_T_shown)
```

**T的更新（预期计算）**：T的更新采用预期偏差机制——将T_shown（这次展现的能力）与当前T比较，决定涨跌方向。

先更新TU，再用新TU计算ΔT。

```
ΔT = 0.20 × (T_shown - T) × (TU_new - T)
T_new = clamp(T + ΔT, 0, TU_new)
```

- 如果 T_shown > T → T上涨（这次表现超出当前水平）
- 如果 T_shown < T → T下跌（这次表现低于当前水平）
- 如果 T_shown ≈ T → T不变或微调

为什么用预期偏差？T的样本量少，每道跨单元题都很珍贵。如果只用"做对就涨、做错就跌"的二元逻辑，会浪费很多信息——比如一道难题做错了但结构方向对，应该比"完全没认出结构"跌得少。预期偏差机制可以更精细地利用每次观测。

### 6.6 W（跨类型权重）分段

| 类型 | W范围 | 说明 |
|------|-------|------|
| 课内跨单元（多单元、难单元） | 0.60~0.80 | 核心考察对象 |
| 跨学科 | 0.50~0.60 | 按难度细分为0.50/0.55/0.60 |
| 初中跨高中 | 0.30~0.50 | 工具性迁移，参考度低 |
| 竞赛 | 0.80~0.999999 | 顶级迁移，无限逼近1但不到1 |

### 6.7 r（解题质量系数）的判定

r 通过多轮引导后评分。根据学生的回答，判断他是否识别了跨单元的深层结构。

| 分数 | 描述 |
|------|------|
| 0.9~1.0 | 学生能在追问下清晰说出"为什么这两个单元能连在一起"，并能指出是哪个条件触发了他这个联想 |
| 0.7~0.8 | 学生能说出涉及哪些单元，但说不清为什么能连在一起 |
| 0.4~0.6 | 学生一开始没看出来，但在追问下能事后领悟 |
| 0.1~0.3 | 学生全程说不清，只停留在套公式层面 |
| 0 | 学生拒绝回答，或思维链完全空白 |

### 6.8 T维度的行为特征

| 阶段 | T的行为 | 原因 |
|------|---------|------|
| 初期（N<5） | 快速拉升，每跳0.05~0.10 | TU初始值0.60，T初始值0.10，(TU-T)大 |
| 中期（N=5~15） | 震荡上行，涨速放缓 | T接近TU，(TU-T)变小 |
| 突破期 | 突然跃升 | 高质量跨单元题推动TU上浮，T获得新增长空间 |
| 后期（N>15） | 稳定在高位，微幅波动 | T和TU几乎重合 |
| 低谷期 | T下跌 | 持续表现不佳，T_shown低于当前T |

### 6.9 参数总表

| 参数 | 值 | 说明 |
|------|-----|------|
| T₀ | 0.10 | 初始迁移能力 |
| TU₀ | 0.60 | 初始迁移上限 |
| α_t | 0.20 | 学习率 |
| δ_up | 0.10 | TU上浮速率 |
| δ_down | 0.09 | TU下浮速率 |
| N | 3 | TU上下浮观测窗口 |
| 上浮条件 | T_shown_max > TU×1.1 且 avg_T_shown > TU | 突破+趋势确认 |
| 下浮条件 | avg_T_shown < TU×0.7 | 持续低迷 |

## 七、Q — 思维品质

### 7.1 本质定义

Q（思维品质） = 觉察和调整的能力——学生知不知道自己是怎幺错的，下次能不能改过来。

通俗说法："会不会学"。

理论依据：Flavell 元认知理论（监测、控制、评估）。

### 7.2 核心原则

1. Q只通过思维链测量。没有思维链，Q不更新。
2. 思维链不让学生主动写，而是对高价值题目发起采集询问。
3. 对题也能涨Q（思路清晰说明觉察能力强）。

### 7.3 五个子维度

| 编号 | 子维度 | 含义 | 对应 Flavell 成分 |
|------|--------|------|------------------|
| Q1 | 事中监控 | 做题过程中能否及时察觉"卡住了/偏了" | 监测（事中） |
| Q2 | 归因准确度 | 事后能否准确说出错因/思路偏差 | 监测（事后） |
| Q3 | 调整清晰度 | 能否说出具体的改进策略 | 控制 |
| Q4 | 反思深度 | 能否提炼通用经验、归类错误模式 | 评估（过程） |
| Q5 | 执行结果 | 下次同类题是否做对了 | 评估（结果） |

### 7.4 数据采集

**触发**：高价值题目触发思维链采集（采集交互工程见《五维工程实现规范》§五）。

**高价值题目定义**：
- 做错的题
- 做对但过程复杂的题
- 涉及关键知识节点的题

**频率原则**：采集频率与当前 Q 负相关——Q 越低越需要采集，Q 越高越少打扰（鼓励主动反思）。具体概率参数见工程规范。

### 7.5 评分方式

按以下标准给每个子维度打 0~1 分（判定执行见《五维工程实现规范》§〇）：

| 子维度 | 评分标准 |
|--------|---------|
| Q1 事中监控 | 0=无察觉，0.5=事后回想起来有，1=过程中主动说"这里不对" |
| Q2 归因准确度 | 0=说不清，0.5=方向对但不准，1=精准 |
| Q3 调整清晰度 | 0=无，0.5=泛泛（"下次细心"），1=具体可执行 |
| Q4 反思深度 | 0=无，0.5=单次改进，1=模式归纳 |
| Q5 执行结果 | 首次思维链时占位0.5，下次同类题验证后更新为1.0（做对）或0（做错） |

### 7.6 Q值的计算

**数据结构**：

| 字段 | 含义 | 初始值 | 范围 |
|------|------|--------|------|
| Q | 全局思维品质指数 | 0.30 | [0, 1] |
| Q1~Q5 | 5个子维度的移动平均 | 0.30 | [0, 1] |
| N | 有效思维链总次数 | 0 | 整数 |

**子维度的更新（移动平均）**：
```
Q_i_new = (Q_i_old × N + s_i) / (N + 1)   （N ≥ 3）
```

冷启动（N < 3）时放大步长，让Q快速收敛到真实水平：
```
Q_i_new = (Q_i_old × 1 + s_i) / 2
```

N在所有子维度上共用（每次有效思维链，N+1）。

**全局Q的聚合**：
```
Q = 0.25×Q1 + 0.25×Q2 + 0.25×Q3 + 0.15×Q4 + 0.10×Q5
```

权重分配的依据：

| 子维度 | 权重 | 理由 |
|--------|------|------|
| Q1 事中监控 | 0.25 | 监测是元认知的起点，事中比事后更稀缺 |
| Q2 归因准确度 | 0.25 | 和事中监控对等，合起来0.5覆盖监测 |
| Q3 调整清晰度 | 0.25 | 控制是把监测转化为行动的关键 |
| Q4 反思深度 | 0.15 | 反思偏高阶，出现频率低，权重稍小 |
| Q5 执行结果 | 0.10 | 结果验证，是Q1~Q4的外部校准，权重最小 |

**Q5的特殊处理（二次更新）**：Q5和其他四个子维度不同——它不能在第一次思维链时就给分，因为"下次同类题做对没"是未来事件。

处理流程：
1. 首次思维链（做错当前题）：Q1~Q4正常给分，Q5先给 0.5（占位）
2. 下次遇到同类题（判断为同类题时）：
   - 做对了 → Q5更新为1.0
   - 做错了 → Q5更新为0
   - 更新方式：Q5_new = (Q5_old × N + 新Q5) / (N + 1)

### 7.7 算例

一个学生第5次有效思维链，各子维度当前值：Q1=0.70, Q2=0.65, Q3=0.55, Q4=0.45, Q5=0.60，N=4。

本次思维链评分：s1=0.8, s2=0.7, s3=0.6, s4=0.5, s5=0.5（占位）。

N=4 ≥ 3，用标准移动平均：

```
Q1_new = (0.70×4 + 0.8) / 5 = 3.6/5 = 0.72
Q2_new = (0.65×4 + 0.7) / 5 = 3.3/5 = 0.66
Q3_new = (0.55×4 + 0.6) / 5 = 2.8/5 = 0.56
Q4_new = (0.45×4 + 0.5) / 5 = 2.3/5 = 0.46
Q5_new = (0.60×4 + 0.5) / 5 = 2.9/5 = 0.58
N = 5

全局Q = 0.25×0.72 + 0.25×0.66 + 0.25×0.56 + 0.15×0.46 + 0.10×0.58
     = 0.180 + 0.165 + 0.140 + 0.069 + 0.058 = 0.612
```

### 7.8 参数总表

| 参数 | 值 | 说明 |
|------|-----|------|
| 初始Q | 0.30 | 默认值 |
| base_prob | 0.7~0.8 | 弹窗基础概率（工程参数，见《五维工程实现规范》§五） |
| 冷启动阈值 | N < 3 | 放大更新步长 |
| Q1权重 | 0.25 | 事中监控 |
| Q2权重 | 0.25 | 归因准确度 |
| Q3权重 | 0.25 | 调整清晰度 |
| Q4权重 | 0.15 | 反思深度 |
| Q5权重 | 0.10 | 执行结果 |
| Q5首次占位 | 0.5 | 等待下次同类题验证 |

## 八、S — 执行稳定性

### 8.1 本质定义

S（执行稳定性） = 学生实际表现与真实能力之间的偏差。

它不是"会不会"（那是K/A/T），而是"稳不稳"——该做对的题做错了，不该错的错了，明明会做的因为计算、审题、状态、心态等原因丢了分。

### 8.2 核心属性

- **全局的**，一个学生一个S
- **不是能力指数**，不搞"增长+上限"那套
- **是失常模式的统计归档**，服务于诊断和干预

### 8.3 七个子维度

| 编号 | 子维度 | 含义 | 数据来源 | 性质 | 是否计入S_global |
|------|--------|------|---------|------|----------------|
| S0 | 波动指数 | 预期得分率与实际得分率的绝对偏差 | 客观计算 | 客观 | ✅ 是 |
| S1 | 计算稳定性 | 计算过程是否可靠 | 自我回溯报告 | 主观 | ✅ 是 |
| S2 | 时间管理 | 时间压力下是否稳定 | 自我回溯报告 | 主观 | ✅ 是 |
| S3 | 审题稳定性 | 审题是否仔细 | 自我回溯报告 | 主观 | ✅ 是 |
| S4 | 步骤稳定性 | 步骤执行是否流畅 | 自我回溯报告 | 主观 | ✅ 是 |
| S5 | 状态稳定性 | 做题前的生理/心理状态 | 轻量自评 | 主观（归因） | ❌ 否 |
| S6 | 考场心态 | 考试过程中的心理波动 | 考试时询问 | 主观（归因） | ❌ 否 |

> 采集方式（回溯环节、弹窗交互）见《五维工程实现规范》§六。

### 8.4 S0波动指数算法

**单次偏差 d**：
```
P_exp = w_K × K_mastery + w_A × A_unit + w_T × T_global
```

权重由题目类型决定：
- 单元内题：w_K=0.3, w_A=0.7, w_T=0
- 跨单元题：w_K=0.2, w_A=0.4, w_T=0.4

```
R_actual = 学生实际得分 / 该题满分
d = |P_exp - R_actual|
```

d的范围：0~1。d越大，说明实际表现与预期偏差越大。

**波动指数 V**：
```
V = 最近N次d的平均值
```
N = 20~30次作答。

**各维度波动**：
```
V_K = 最近N次d_K的平均值（仅当该题涉及K偏差时）
V_A = 最近N次d_A的平均值（仅当该题涉及A偏差时）
V_T = 最近N次d_T的平均值（仅当该题涉及T偏差时）
```
其中d_K, d_A, d_T从错因分析中拆解。

**关于超常发挥的处理**：S0使用绝对偏差 d = |P_exp - R_actual|，因此无论是失常（预期高但实际低）还是超常（预期低但实际高），只要有偏差，都计入波动指数。这是因为"超常"本身也是一种不稳定——一个学生如果经常"该做对的做错，不该做对的蒙对"，他的发挥就是不可预测的，这本身就是S要反映的问题。

### 8.5 全局稳定性指数 S_global

**公式**：
```
S_global = w_self × Self_stability + w_obj × Obj_stability
```
其中：
- Self_stability = 1 - Σ(w_i × 失常率_i) （自报部分，来自S1~S4）
- Obj_stability = 1 - V （客观部分，来自S0波动指数）
- w_self = 0.6
- w_obj = 0.4

**Self_stability 的详细计算**：
```
失常率_i = S_i的失常次数 / S_i的总观测次数（i=1~4）
w_i（动态权重）= 失常率_i / Σ(失常率_j)
```
失常率越高的子维度，权重越大。这样S_global会重点反映学生最薄弱的稳定性环节。

**Obj_stability 的详细计算**：
```
Obj_stability = 1 - V
```

**算例**：

一个学生：
- S1失常率=0.35，S2失常率=0.05，S3失常率=0.12，S4失常率=0.08
- V = 0.18

Step 1：Self_stability

Σ失常率 = 0.35+0.05+0.12+0.08 = 0.60

w_i：
- S1: 0.35/0.60 = 0.583
- S2: 0.05/0.60 = 0.083
- S3: 0.12/0.60 = 0.200
- S4: 0.08/0.60 = 0.133

Σ(w_i × 失常率_i) = 0.583×0.35 + 0.083×0.05 + 0.200×0.12 + 0.133×0.08
= 0.204 + 0.004 + 0.024 + 0.011 = 0.243

Self_stability = 1 - 0.243 = 0.757

Step 2：Obj_stability

Obj_stability = 1 - 0.18 = 0.820

Step 3：S_global

S_global = 0.6 × 0.757 + 0.4 × 0.820 = 0.454 + 0.328 = 0.782

### 8.6 S与K/A/T的边界

| 情况 | 归属 |
|------|------|
| K/A/T达标，做错了 | S问题（失常） |
| K/A/T达标，做对了但步骤异常 | S问题（隐性损耗） |
| K/A/T不达标，做错了 | K/A/T问题，不进S |
| K/A/T不达标，做对了（侥幸） | K/A/T问题，不进S |
| 预期低但实际高（超常） | S0计入波动（d>0），但不视为失常 |

### 8.7 输出呈现

> 稳定性指数、波动指数、失常画像、状态/心态记录的输出文案与展示形式（原示例）已移至《五维工程实现规范》§六。

### 8.8 指导策略

| 子维度 | 失常率高时的建议 |
|--------|----------------|
| S0 波动指数高 | 分析偏差来源——是集中在某个单元、某种题型，还是时间压力下？ |
| S1 计算稳定性 | 每题做完后反向验算；草稿纸分区书写 |
| S2 时间管理 | 限时训练；学会"跳做→回头"的节奏 |
| S3 审题稳定性 | 读题时圈画关键条件；慢读一遍再动笔 |
| S4 步骤稳定性 | 关键步骤停顿确认；写完一步回头看一步 |
| S5 状态稳定性 | 保持规律作息；考前调整生物钟 |
| S6 考场心态 | 模拟考脱敏训练；深呼吸/正念练习 |

## 九、各维度数据源独立性（非重叠原则）

### 9.1 核心原则

**每个维度有且只有自己独占的信号源，一个信号不能同时用于计算两个维度。**

### 9.2 信号分配

| 维度 | 独占信号 | 不使用的信号 |
|------|---------|------------|
| K | 知识点环节难度×环节作答（D_kp×P_kp，2026-08-17 粒度修订，见 §4.4） | 不使用整题对错，不依赖题目整体难度 |
| A | D×η（有效刺激量），A/U框架 | 不直接使用对/错结果 |
| T | W×D×r（跨类型×鉴别力×解题质量），T/U框架 | 不处理单点对错 |
| Q | 思维链文本（独占） | 不接受任何代理指标 |
| S | S0波动指数（客观）+ S1~S4失常自报（主观） | 不判断"这是粗心还是不会" |

### 9.3 跨维度参数传递

K维度的加权得分法不需要外部参数。

```
K的计算只依赖于：
  难度 0.01-0.99 ← 判定（5维度加权）
  过程分 0-1    ← 判定（连续 0~1）
  不需要 P(S)、P(G)、P(L₀)、P(T) 等参数
```

K向其他维度传递的信号：
- 具体到题目的过程分和思维链 → 提供给Q维度
- 超纲/不超纲标记 → 提供给学习进度指标

**五维不重叠**：每个维度有自己独占的信号源，不存在两个维度用同一数据算不同分的情况。
