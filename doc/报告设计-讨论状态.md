## 一、已决策（用户拍板）

| # | 决策 | 说明 |
|---|------|------|
| D-01 | **报告定位 = 处方**（错因 + 行动） | 面向学生；诊断不落到行动 = 没有诊断（文档原有，确认） |
| D-02 | **不露具体数据** | 学生只看结论文字，不看 D/P/掌握度数字 |
| D-03 | **P0 范围 = ①结论 + ③行动建议 + ④趋势占位 + RAG 自增强** | ②模式识别、⑤归因（Q 维度依赖）排除在 P0 |
| D-04 | **生成方式 = 规则为主 + AI 整理输出** | 规则算法生成结构化内容，AI 调用工具后整理成报告文案 |
| D-05 | **入口 = 判完题「可选是否查看」** | 不强制自动跳转 |
| D-06 | **报告按知识点组织**（不是按题） | 题目是证据；知识点是骨架 |
| D-07 | **题型（解题模式）是重要维度** | 注意：是「恒成立求参数」这类解题模式，不是「选择/填空/解答」分类 |
| D-08 | **A 记录单元级（宪法 §5.3）** | 不拆「单元×题型」——A 的容器就是单元，题型不参与 A 统计拆分 |
| D-09 | **RAG 核心机制 = 模糊匹配**（embedding） | 题型不是精确索引 |
| D-10 | **题型 = 语义锚**（图式级） | 题型文本与题目一起向量化，让模糊匹配发生在图式层而非表面层 |
| D-11 | **理论依据 = 图式理论 + 产生式系统（ACT-R）** | 题型 = 产生式触发条件；专家按深层结构（图式）分类问题（Chi et al.） |
| D-12 | **题型锚实测成立（2026-08-15 实测）** | text-embedding-v4 双组测试：同类相似度提升 0.1+（0.59→0.74~0.83），与干扰间距拉大一倍 → 阈值截断可靠 |
| D-13 | **RAG 入库内容 = 题目文本 + 题型 + 知识点** 一起向量化 | 零额外成本，语义锚自动生效 |

## 三、讨论中形成的链路草图

```
判完题（questions 已有判定数据）
   │
① 批次汇总 ── 读批次所有判定
   │
② 每题结论 ── P 分级 → 文字（+题型 +知识点 +错因）
   │
③ 卡点溯源 ── 知识点依赖链 + 题型图式链 → 找卡点
   │
④ 补缺漏计划 ── 卡点 → [今日一步/步骤/完成标准]
   │
⑤ AI 整理 ── 规则结果 → 报告文案
   │
⑥ RAG 入库 ── 题目+题型+知识点+报告 → embedding → mastery_logs
   │
⑦ 前端展示 ── 结论卡片 + 行动计划 + 趋势占位（可选查看入口）
```

## 四、关键认知（讨论产出，非决策）

- **题型图式 = A 维度的本质**（识别运用 = 图式匹配）——报告按知识点×题型组织 = 按 K×A 组织
- **A 的容器是单元（宪法），题型是证据标注不是统计容器**
- **RAG 模糊匹配 + 题型语义锚**：召回靠 embedding，题型让召回发生在图式层
- 报告 = 仪表盘（趋势）+ 处方（错因+行动）；②模式识别需多次诊断数据，P0 排除合理
