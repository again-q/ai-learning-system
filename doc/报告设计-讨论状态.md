| D-10 | **题型 = 语义锚**（图式级） | 题型文本与题目一起向量化，让模糊匹配发生在图式层而非表面层 |

| D-15 | **检索 = 时间过滤 + 模糊匹配** | ① 数据库 where {userId, createdAt ≥ now-30天} ② 窗口内内存 cosine ③ top-K；轻量自建不引入向量库 |

## 三、讨论中形成的链路草图

```
判完题（questions 已有判定数据）
   │
① 批次汇总 ── 读批次所有判定
   │
② 每题结论 ── P 分级 → 文字（+题型 +知识点 +错因）
   │
③ 卡点溯源 ── 知识点依赖链 + 题型图式链 → 找卡点
   │
④ 补缺漏计划 ── 卡点 → [今日一步/步骤/完成标准]
   │
⑤ AI 整理 ── 规则结果 → 报告文案
   │
⑥ RAG 入库 ── 题目+题型+知识点+报告 → embedding → mastery_logs
   │
⑦ 前端展示 ── 结论卡片 + 行动计划 + 趋势占位（可选查看入口）
```

## 四、关键认知（讨论产出，非决策）

- **题型图式 = A 维度的本质**（识别运用 = 图式匹配）——报告按知识点×题型组织 = 按 K×A 组织
- **A 的容器是单元（宪法），题型是证据标注不是统计容器**
- **RAG 模糊匹配 + 题型语义锚**：召回靠 embedding，题型让召回发生在图式层
- 报告 = 仪表盘（趋势）+ 处方（错因+行动）；②模式识别需多次诊断数据，P0 排除合理
- **时间 RAG + 置信度**：检索先按时间窗硬过滤，再模糊匹配；置信度规则层分级（阈值+命中数），无命中宁缺毋滥；判题/报告复用同一检索

## 三、深挖根因讨论（2026-08-17，进行中，先记录不定稿）

### 已确认的方向
1. **根因深挖基于历史做题模式**（RAG 30 天窗口），单次错只到「直接原因」层
2. **根因话术 = 程度化**（「问题可能出在…」+ 证据 + 置信度），不断言
3. **21 项技术 §21 四步流程**：收集现象 → 定位直接原因 → 探索思想根源（七层地图）→ 规划改进
4. **七层根源地图 vs 五维对应**：K=知识与理解、A=经验与见识、T=思维格局、Q=学习技术+策略监控、S=情绪+内在资源
5. **涂改/停顿 = 弱信号**（写错/太急/硬冲多义），只能作参考线索，不能断言（转录也未必可靠）
6. **二次复核 = 报告异议**（不是参数确认）：报告生成后对单模块异议 → 该模块重新生成（一次复核没发现的问题，报告归因错时纠正）
7. **报告 = 单向**；顿悟在报告内引发（AI 教练不是 1.0）；问题链可带走（校内触发，蔡格尼克）
8. **检验 = 成就感环节，非强制**：开放建议（讲给同学/做同类题），不布置任务

### 概念边界不清（K 层 · P 多扣分）——待完善
- **定义**：概念/公式的适用前提被忽略或误用 → 属 K 层（知识点属性）
- **处理**：judgeOne prompt 加规则——概念边界不清时 P 压低（比一般过程错误多扣分）
- **示例（强调只是例子，待 AI 判定时验证）**：
  - 判别式 Δ≤0：前提「二次项系数≠0」+ 适用「R 上恒成立」——区间恒成立误用
  - 均值不等式：前提「各项为正」+「定值」
  - 对数：真数 > 0
  - 乘除负数变号、开方/绝对值条件
- **边界**：分类讨论漏情况 = 思想方法（A/方法层）**不是**概念边界；计算错/粗心 = 执行层，不归此
