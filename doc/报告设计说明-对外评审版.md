# 诊断报告设计说明

> 面向：评审者 / 外部顾问 / 新加入的协作者
> 目的：让你在不了解项目内情的情况下，能评判这份报告设计是否成立
> 日期：2026-10-05
> 状态：设计稿，未实现

---

## 〇、用一句话说清这个产品

**给高中生（尤其是数学中上水平的学生）的「解答题过程审阅」——告诉他哪里会被扣分，以及同一处他丢过几次。**

不是知识问答、不是题库、不是网课。**它做的事是：看学生写的过程，指出被扣分的地方。**

**为什么不做"你哪里不会"**：目标用户是"基本都会、但总在细节上丢分"的学生。
对这类学生，"你不会什么"基本是空集；**他真正的困境是"为什么丢分，自己看不出来"**。

---

## 一、报告要回答的三个问题（用户原话）

> 「能够帮助我**发现我在中档、中上题甚至难题上面的缺失的地方**，并且**给我一些指导的方向**，让我能发现**原来这里错了**，以及**我能够明白自己有哪些地方不足要补**」

拆成三件事，**顺序不能反**：

| 顺序 | 要回答 | 现在系统的差距 |
|---|---|---|
| ① | 我在哪儿缺 | 三段话点评，笼统，没有排序 |
| ② | 原来这里错了 | 给"过程风险"这种标签 —— **标签不等于认知** |
| ③ | 该补什么 | "下次把式子写完整" —— **通用建议，对谁都一样** |

## 二、我们有什么（数据与能力清单）

### 2.1 输入：学生拍一批题

```
拍照（多张）→ 上传 → 视觉转录 + 拆题 → 学生核对 → AI 判定 → 报告
```

**关键：一次是"一批题"，不是一道题。** 这很重要 —— 一批题构成一个难度剖面。

### 2.2 数据清单（线上实测填充率）

| 数据 | 内容 | 填充率 | 可靠吗 |
|---|---|---|---|
| **题面** | 转录的题目文本 | 100% | 🟡 转录可能错，学生可核对 |
| **学生笔迹** | 裁剪后的单题照片 | 75% | ✅ 客观 |
| **痕迹描述** | 涂改/圈画/划线的文字描述 | 100%（有照片的） | 🟡 模型读的 |
| **过程分 P** | 0~1，过程与正确答案的距离 | 92% | 🟡 模型判，实测抖动中位 0 |
| **难度 D** | 0.01~0.99，题目固有属性 | 100% | 🟡 模型判，抖 0.03~0.16 |
| **知识点使用** | 这道题用了哪些知识点（1~5 个） | 100% | 🟡 模型判，**名字一致率 60%** |
| **题型** | domain/pattern/variant 三层 | 100% | 🔴 **一致率 22.9%** |
| **错误归因** | K/A/T/S 四维 + 一句话描述 | 70% | 🟡 |
| **错误层级** | skill/rule/concept | 71% | 🟡 一致率 77.1% |
| **参考解法** | AI 推的解题过程（3~8 步） | 83% | 🔴 **零校验** |
| **官方分** | 智学网同步的阅卷分数 | **38%**（23/61） | ✅ **最硬，但覆盖少** |

### 2.3 能力清单（我们能做到什么）

| 能力 | 现状 | 实测数据 |
|---|---|---|
| 判定"这道题做得怎么样" | ✅ 能做 | 三态一致率 **91.4%** |
| 判"某个动作发生了没有" | ✅ 能做 | 检查表式 **100% 一致**（4 题） |
| 判"这道题用了哪些知识点" | 🟡 名字不稳 | 一致率 **60%** |
| 判"这是什么题型" | 🔴 不可用 | 一致率 **22.9%**，194 种写法 |
| 判"他卡在哪一步" | 🟡 部分 | 依赖模型自由切分，一致率低 |
| 从清单里选知识点（Jev） | ✅ 能做 | **准确率 100%**（12/60/254 候选） |
| 判"这类题他以前错过吗" | 🟡 部分 | 依赖 embedding 检索 |

### 2.4 我们用不了什么（诚实列出）

| 拿不到的东西 | 原因 |
|---|---|
| **思考时间** | 没有采集 |
| **尝试次数** | 没有采集 |
| **学生的主观想法** | 需要他说话，2.0 才做 |
| **做对的题的官方分** | 接口没抓到（可修） |
| **跨题型的稳定标识** | 模型自由命名，每次不一样 |

## 三、报告的七段结构

### ① 这批的事实

```
19 道题：做了 10 道，9 道没作答
本批判定来源：系统判定（无官方分）

数列 · 3 道
  都在"确定范围"这一步开始偏 —— 其中 2 道此处有涂改
  3 道都没走到最后

导数 · 4 道
  都走到最后，没有涂改
```

**设计意图**
- **只摆事实，不判定**（"9 道没作答"是事实，"9 道不会"是判定 —— 后者禁止）
- **不出现正确率数字**（数字会被当成能力值）
- **价值在"同一性"**：「3 道都在同一步」是学生自己看不出来的（他的记忆按单题存）

### ② 单元情况

```
数列单元
  常考的动作：确定范围 / 化简变形 / 求和
  你的表现：  确定范围 2/5，化简变形 5/5
```

**设计意图**
- **按单元组织**（教材单元，如"数列""导数"）
- 给"动作的做到次数"，**不给分数**
- **不跨单元比较**（单元难度不同，比了不公平）

### ③ 该改的

```
「确定范围」这个动作，你这批 5 道里有 3 道没做。

凭什么：
  · 另 2 道同类题你做了这个动作，都走到最后
  · 没做的 3 道里，有 2 道在这个位置有涂改
    （笔迹：你在这一步划掉过重写）

                              [ 我不服 › ]
```

**设计意图**
- **每条必须附「凭什么」**，三种依据至少一种：
  1. 引题目条件
  2. 引笔迹事实
  3. 引官方分
- **三种都拿不出来就不报** —— 宁可只报 2 条真的，不报 10 条凑数
  （报错一条，学生就不再信后面九条）
- **「我不服」是地基** —— 学生必须能反驳"这步扣不扣分"

### ④ 想一想

```
想一想：你涂改的那一刻，是觉得哪里不对？
        那 2 道没涂改的，和这 3 道，差别在哪？

        （想不出来再看 ›）
        ┌────────────────────────────────┐
        │ "我写到这发现 x 得大于 0，但想着   │
        │  先把式子化简完再说，结果后面就    │
        │  不对劲了。"                     │
        └────────────────────────────────┘
```

**设计意图**
- **问题要问在他答不出的地方**
  - ❌"你涂改时觉得哪里不对"（他答得出，问了等于没问）
  - ✅"那 2 道没涂改的和这 3 道，差别在哪"（需要跨题视野，他做不到）
- **参考答案默认折叠**，且示范的是"怎么自我观察"，不是标准答案
- **参考答案用第一人称**（学生视角自述，让他认出"这确实是我"）

### ⑤ 一个动作 + 框架

```
一个动作：
  把这道题讲给一个同学听，讲到他听懂为止。

下次可以自己过一遍：
  摆过程 → 找从哪开始不对 → 想为什么 → 问自己下次在哪停一下
```

**设计意图**
- **动作要宽泛**（换题型依然成立）—— "讲给同学听"训练的是表达能力，不是这道题
- **框架是可撤的脚手架** —— 目标让产品能被丢掉

### ⑥ 逐题（材料层）

```
第 3 题
  题目：…
  你的过程：［照片］
  这一步：确定范围 未做
  凭什么：这个动作在笔迹里找不到
                              [ 我不服 › ]
```

**设计意图**
- **逐题是"反驳的落点"，不是"讲这道题"**（他会做，不需要讲）
- 每条聚合结论都要能点回具体某题

### ⑦ 纵向（能力变化）

```
数列递推求通项 + 错位相减       5 道题

      确定范围  化简  求和  验证
9/04 │    ✗      ✓    ✓    ✓
9/11 │    ✗      ✓    ✓    ✗
9/18 │    ✓      ✓    ✓    ✗
9/25 │    ✓      ✓    ✓    ✓
              ↑ 这一列从 ✗✗ 变成 ✓✓
```

**设计意图**
- **画动作的 ✓✗ 序列，不画"得分率曲线"**
  （得分率会受难度构成影响；动作的 ✓✗ 是可比的）
- **必须有样本量标注**（5 道题）—— 否则 1 道也能画线，学生以为那是趋势
- **"能力变化"的定义 = 某个动作从 ✗ 变 ✓**

## 四、设计原则（约束）

| # | 原则 | 为什么 |
|---|---|---|
| 1 | **只观测纸面事实，不归因来源** | 抄了一份好解法也算"他写出来了" |
| 2 | **算不出来的就说算不出来** | "这批没考到你的 X"是合法结论，不是失败兜底 |
| 3 | **不揣摩** | 不猜学生心理；"不严谨"这种标签禁止 |
| 4 | **不给动作** | 只定位问题 + 给问题让他想；"下次细心点"这类禁止 |
| 5 | **只跟自己比** | 不引入班级/他人参照 |
| 6 | **报告里的每条结论必须可反驳** | 不能反驳的判卷老师，学生不会信第二次 |
| 7 | **判定来源要标注** | "系统判定"不能写成"阅卷结果" |

## 五、我们故意不做的

| 不做 | 理由 |
|---|---|
| **正确率/能力分数** | 会被当成能力值；且单元难度不同，分数不可比 |
| **跟班级比** | 分母是别人的数据，且那场考试里没有他 |
| **"你缺 XX"** | 评判缺失 → 学生防御；改成给问题 |
| **直接给答案** | 那不是审阅，是订正；学生要的是自己想通 |
| **打卡/通关** | 行动不是通关条件 |
| **Q（元认知）评分** | 需要学生说话，放 2.0；1.0 只给框架 |

## 六、这份设计依赖的两个缺口

**报告要落到"行"上（说清是哪一步），必须有步骤级信号。**

而现在：

| 缺口 | 现状 | 影响 |
|---|---|---|
| **① 算子级判定**（哪一步做了/没做） | ❌ 未建 | ①②③⑥⑦ **都依赖它** |
| **② 题型稳定标识** | 🔴 一致率 22.9%，194 种写法 | ⑦ 纵向做不出来 |

### 缺口 ① 的技术依据

已实测：**"某个动作发生了没有"这个二值判断，AI 能做到 100% 一致**（4 题）。

做法是"检查表式"：
```
先由题目推出「该有哪些动作」（不看学生）
再逐个到笔迹里找：这个动作出现了吗？
↑ 不需要切分笔迹，只需在整张笔迹里"找某个形式"
```

**为什么不用"切分"**：模型自由切分的段数一致率只有 62%~75%（会变成噪声源）。

### 缺口 ② 的技术依据

已实测：同一类题，模型给出的题型描述有 **194 种写法，一致率 22.9%**。

**可选解**：
- 受控题型清单（从清单里选，不是自由写）
- 或 embedding 归并（同义写法归到同一类）

## 七、评判这份设计时，可以问的问题

**如果你来评审，这几个问题最有价值：**

1. **"只观测纸面事实"这条守得住吗？**
   比如"他涂改了"是事实，但"他不确定"是推断。边界在哪？

2. **"凭什么"三种依据，真的能覆盖大多数结论吗？**
   如果大部分结论只能引"笔迹事实"，那报告的多样性是否足够？

3. **不给分数、不给分数变化，学生怎么感知"我进步了"？**
   靠动作的 ✓✗ 序列够吗？

4. **④ 问问题这一节，学生真的会想吗？**
   还是直接看折叠的参考答案？（"元认知低的学生会直接看答案"是已知风险）

5. **⑦ 纵向需要 5 个以上同类题才有意义。**
   而一个学生一学期可能只做 2~3 道同类题 —— **这个视图会不会长期是空的？**

6. **判定有抖动（三态一致率 91.4%，不是 100%）。**
   报告是基于单次判定写的，**判错的那次会不会误导学生？**

## 八、外部审查意见与回应

> 2026-10-05 收到一份外部 AI 审查。结论：**设计成立，属当前教育产品的顶尖水平**
> （设计理念 9.5/10，认知科学合理性 9/10，当前可执行性 7/10）
>
> 它指出了三个短板。下面逐条回应，**三条都已列为待办。**

### 审查认可的部分（与设计意图一致）

| 审查的判断 | 对应的设计 |
|---|---|
| 解决「知识错觉」 | ③ 的"凭什么"是外部认知支架，帮他看到看不到的模式 |
| 「只观测纸面事实」符合行为主义 | 禁止"粗心/不严谨"标签 —— 归因会让学生接受一个模糊解释 |
| 「我不服」利用认知失调 | 给低成本质疑通道；但**证据站不住会转为不信任** |
| 不给分数符合掌握导向动机 | Dweck 成就目标理论：分数激活"表现目标"，动作 ✓✗ 激活"掌握目标" |
| 纵向要 5+ 样本，防小样本谬误 | 避免学生和产品共同过度推论 |

### 短板 1（审查认定为**最大风险**）：④ 的提示词质量未验证

审查原话：

> 如果问题太抽象（"你想一想为什么会错？"），学生不知道该怎么想；
> 如果问题太具体（"你是不是忘记考虑定义域了？"），那就变成了暗示答案。

**它给的解法：渐进式提示（三层）**

```
第一层：开放式问题      "这两道题的差别在哪？"
   ↓ 想不出来才展开
第二层：方向性提示      "看看第一步的条件"
   ↓ 还想不出
第三层：具体提示        "左边那题 x 范围是全体实数，右边呢？"
```

**回应**：接受。这条正好解决我们已知的风险（元认知低的学生直接看参考答案）。

**待办**：把 ④ 的参考答案从"一段示范"改成"三层渐进"。

### 短板 2：20% 匹配不到历史同类题，需要降级方案

审查引用的"同类题能抓到 80%"——**这个数需要修正**：

| 数字 | 含义 | 来源 |
|---|---|---|
| **22.9%** | 题型 pattern **一致率**（同题两次判，写法是否相同） | ✅ 已有评测（D6 基线） |
| **0.74~0.83** | 命中题型的**余弦相似度**（干扰项 0.54~0.58） | 🟡 冒烟测试（仅 9~14 条语料） |
| **~80%** | 审查引用的"能抓到同类题" | ❌ **本项目未测，待验证** |

**这里有个比审查更严重的问题**：22.9% 指的是"**同一道题判两次，写出来的题型描述不一样**"——
它是"检索主键稳不稳"，不是"能不能检索到"。

```
如果题型主键本身不稳（一致率 22.9%）
→ "同类题"的归并就是随机的
→ 检索到的"历史同类题"可能根本不是同类
→ 纵向序列可能是几道不相干的题拼出来的
```

**这条已写进 §六 缺口 ②。**

**回应**：接受审查的降级方案 ——
```
① 报告中明确标注"数据来源：X 道历史同类题"
② 少于 5 道 → 直接显示"样本不足，暂不展示趋势"
```

**待办**：把"样本不足就明说"写进 ⑦ 的设计。

### 短板 3：成本可能限制使用频次

审查原话：

> 如果学生一次上传 20 道题，单次成本就是十几块钱。
> 但高频次使用才是有效的 —— 每周甚至每天用，才能形成时间序列。

**回应**：**成本结构已在 2026-10-05 实测，结论与审查的估计不同：**

| 环节 | 现状 | 优化后 |
|---|---|---|
| 知识点选择 | ¥0.027 | **¥0.0017**（换 Jev，准确率 80.7%→100%） |
| 单题判定 | ¥0.0031 | ¥0.0031（不动） |
| 报告生成（摊薄） | ¥0.0012 | ¥0.0006 |
| **单题合计** | **¥0.031** | **¥0.0054** |

```
一批 20 题：现在约 ¥0.62 → 优化后约 ¥0.11
```

**"十几块钱一批"偏高约 20 倍** —— 因为审查按"每题跑一次报告"估，而报告是**每批一次**。

**但审查的核心担忧成立**：高频使用要求成本足够低，**优化后可支撑每周使用**。

**待办**：报告生成成本仍有估算成分（`max_tokens` 实际用量、工具循环轮数未测）。

### 审查没注意到、但我们认为更致命的一条

审查认可了 ⑦ 纵向，**但没注意到它可能长期是空的**：

```
⑦ 需要"同一题型 ≥5 道"
而一个学生一学期，同一题型可能只做 2~3 道
→ 这个视图可能长期只有 2 个点，连成一条无意义的线
```

**已列在 §七 第 5 条，仍待解决。**
